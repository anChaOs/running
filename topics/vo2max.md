# VO₂max｜最大摄氧量到底是什么？

## 种子

好的，是个好的提议，以后找一期，单独聊聊vo2max / 把vo2max聊透。

从vo2max的概念，定义，误区出发，到如何测量，如何使用vo2max指导训练，等等。

（Fatmax 备稿引申：%VO₂max 不是配速打折；安超：没讲清不对观众讲——这期要真聊透。）

## 一句话

VO₂max 是身体用氧的上限；百分比加在氧耗上，不是把配速做数学打折；能指导分区，但不能单靠它安排所有课。

## 可能拆成（成片结构草稿）

### 1. 概念与定义
- VO₂：单位时间氧气消耗量（常用 mL/kg/min）
- VO₂max：递增负荷下氧耗抬不上去的峰值／平台
- 它量的是「心肺＋肌肉用氧」的综合上限，不是单一器官分数

### 2. 常见误区
- %VO₂max ≠ 配速打折（3:40 的 50% 不是 7:20）
- VO₂max 高 ≠ 一定跑得快（还要经济性、阈值、耐久）
- 手表上的 VO₂max 分数 ≠ 实验室测值
- 「有氧区／二区」≠ 某个固定 %VO₂max 的精确点
- 和 Fatmax／燃脂区别混：一个是用氧上限，一个是脂肪氧化峰值强度

### 3. 如何测量
- 金标准：面罩 + 跑台／功率车递增负荷，画强度–氧耗曲线
- 力竭或氧耗平台判 VO₂max；亚极量推算是估
- 有了曲线：找氧耗 ≈ 0.5／0.6／0.8／0.9×VO₂max 的点 → 对应配速／功率／心率
- 手表／场地测试：方便但误差来源要说清

### 4. 如何用 VO₂max 指导训练
- 用 %VO₂max（或由其换出的配速／心率）定强度带：轻松有氧、阈值附近、VO₂ 间歇等
- VO₂max 间歇（如 3–5 分钟硬段）目的是刺激靠近上限的有氧功率，不是「天天跑在 max」
- 进步看：同样配速心率／氧耗更省，或测得上限上移；别只盯手表分数每天跳
- 边界：马拉松表现还吃乳酸阈值、脂肪利用、补给、热适应等；VO₂max 是天花板之一，不是唯一旋钮

### 5. 收口可拍句
- 先人话：它是「你这台发动机用氧的上限」
- 再亮名：VO₂max
- 带走：百分比对氧耗，不对配速做除法；表分参考，课表看目的
