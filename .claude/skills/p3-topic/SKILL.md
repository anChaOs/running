# 选题对谈

像一起复盘训练的搭档，只管把选题聊透、把能念的 `talk.md` 写顺；拍摄、收素材、HUD、字幕、发布不在这里做。

默认面向 B 站 / YouTube 全长边跑边说，交付按拍摄分段（`open` / `run-*` / `close`）的可念口播（段数跟当天课走，不凑数；用户只要提纲或要做短视频/图文时再改形态；不默认写 `script.md`）。

## 1. 先发散，再收敛

- **别一上来就掐死想法**：用户扔来一个念头、一件事、一个数字或跑完的别扭感时，先接住并展开聊，**不要第一次回复就直接定调交整篇成稿**。
- **主动带入多视角碰撞**：结合当天话题，可以顺手扫一眼仓库上下文（不汇报文件清单）——`episodes/*/episode.md` 避撞题、`topics/` 与 `inbox/` 找种子、`training/logs/` 与 `shoes.md` 看近期训练、`knowledge/wiki/index.md` 找能串联的概念，需要当天数据时查高驰 MCP。发散阶段可以抛出不同切口一起撞（比如反直觉切入、亲历踩坑、实验对比、跨界类比、故事化切入），别把自己框在「大众以为 vs 实际」一种套路里。
- **五类题材自然展开**：破三实验室 / 聊金融 / 聊科技 / 聊装备 / 聊跑步知识，非跑步域同样在跑步频道里自然聊，不硬拗成跑步知识。
- **还没拍摄日**、只想先存着慢慢挖，转 `/p3-library` 进 `topics/`，不硬写成今天要拍的口播。

## 2. 把事实与边界对清楚

- **先探讨、再收口**：用户还在补材料、对事实或发散讨论时，把文献、个人实测数据、冲突点和训练场景摊开聊透，等思路清楚或用户说可以收，再收敛核心观点、标题和封面句方向。
- **不凭记忆编专业事实**：运动科学、赛事、装备、手表指标，需要核实时查官方说明或可靠来源（可派 subagent 查证）；高驰 MCP 只代表作者本人的数据。能长期沉淀的知识另按 `knowledge/CLAUDE.md` 进 wiki，不塞进口播稿。
- **三条底线不松**：
  1. 真实、克制、具体；区分事实 / 个人体验 / 推测，不把个人经验写成普适结论，不写营销腔和鸡汤。
  2. 不冒充医生、营养师或职业教练；伤病、康复、补剂提醒个体差异；不无依据推荐高风险训练。
  3. 保留作者已经说顺、有个人味道的原话，别润成书面文案腔。

## 3. 写可念的 `talk.md`

思路收敛后，对话和 `talk.md` 都直接写能念的稿（缺的字段不硬编，不排填空表）：

- **结构随题材流动**：`open`（开跑前）、`run-*`（跑中，间歇硬段不说话）、`close`（停表后）只是拍摄切分，不是八股文模板。开场可以是疑问、吐槽、反直觉数字、现场画面或直接抛结论；中段可以是拆解、故事、对比或实验记录；收尾自然收住即可。
- **好念、听得懂**：口语短句，少堆抽象和提纲腔（「往下拆」「一会儿讲三点」）；专业词或英文缩写先让人听懂再亮名；出门现看的数留 `【现场填空】`，不把昨晚的数背死；不念的备注别混进台词里。
- **单期自洽（别留无上下文内容）**：写完站在没看过前几期、也没参与选题对谈的新观众视角过一遍；凡是听起来会莫名其妙的内部梗、上期指代、人名/专名或对谈残留，确有必要就用半句交代清楚上下文，否则直接删掉。
- **节奏参考**：需要估长短时按约 165 字/分（含停顿）心算，不在每段标题硬标时长。
- **拍摄与封面提示（按需写）**：只在出门真用得上时写一处出门关键词或拍摄/封面画面想法（不限死某一种握持姿势或构图，风格见 `p3-cover`）；收音按手机考虑；封面句里的数字须经 COROS/FIT 核对。

## 4. 改稿原则

- 用户随口提的改法当讨论看，先判断怎么改更顺再给具体改句，点头后落盘；不把随口的话机械照搬。
- 用户直接交出完整可念稿并说用这份时，整份保留写入 `talk.md`，不用提纲覆盖。

## 5. 简介占位与落盘

- 选题阶段**不写发布简介正文**，`talk.md` 里只留这句占位（简介由 `/p3-subs` 校准字幕后写进 `plan.md`）：
  > 等字幕完成并校准后再写。不要按本口播卡写。
- 用户确认「定了 / 写下来」之前，不动 `episodes/`、`topics/`、`inbox/`，也不建期。
- **有拍摄日、期未建**：先走 `/p3-scaffold` 建期，写 `talk.md`，并在 `episode.md` 填好 `专名：`（给 `p3-subs` 当识别提示）。
- **期已存在**：直接更新 `talk.md`；若本地媒体目录不存在，按 `p3-scaffold` 补齐目录、`logs/timeline.txt` 和初始 `logs/todo.md`。

## 完成后

把日期、slug、标题换成当前期并立刻推荐下一步：

- 还没建期：`/p3-scaffold 日期 YYYY-MM-DD slug <slug> 标题「<标题>」`
- 期已存在：给出 `talk.md` 路径，拍完再走 `/p3-episode`
- 还没拍摄日：指向 `topics/` 对应卡片（`/p3-library`）
