# 封面

封面核心目标只有两个：**在手机小图上一眼看懂、让人想点，且点进去不翻车**。和 HUD 互不依赖，可与 `p3-hud` 并行。遵守 `p3-episode` 全局协议（封面不在 `logs/todo.md` 步骤里，不设等待点，不自动打开图片查看器）。

## 硬性底线（只有这 5 条，其余都可以变化）

1. **小图一眼可读**：封面句大字必须够大、对比够强，不能缩成弱小字或塞在角落；背景干净不抢字，无残字/乱码；不堆第二句鸡汤。
2. **三比例各自构图**：产出 `4:3`、`3:4`、`16:9` 三张独立排版图，**不要拿 16:9 粗暴裁切**（会削头切字）。
3. **人物保真**：有人出镜时只用真人实拍或抠出的人像像素，**不用生图模型重画人脸**（身份会漂）。
4. **内容真实 + 数字核准**：画面承诺与视频一致；心率、配速、里程等数字以 COROS/FIT 或口播核准数为准；不用 HUD preview 或糊帧凑数。
5. **不扰主链**：换封面不重渲 HUD；只写文件，把路径发用户看。

## 保持多样性：按题材选视觉路线（不要每期套死同一模板）

动手前先扫一眼最近几期的封面，**避免连续几期构图、配色、背景完全撞脸**。根据本期题材挑最贴切的路线：

| 视觉路线 | 适合题材 | 玩法与变化点 |
| --- | --- | --- |
| **A. 人物抠图 + 创意底** | 观点输出、反常识拆解、聊科技/金融 | 不必每期都「夜景霓虹 + 粗白描边 + 左字右人」：背景可换清晨自然光、胶片颗粒、高对比极简色块、杂志排版、赛场/城市建筑等；`compose_cover.py` 支持 `--side left/right` 换边、`--title-color` 换主题强调色、`--stroke-frac` 调细或弱化描边 |
| **B. 实景氛围原片 + 局部压暗大字** | 赛事纪实、晨跑/雨跑体验、训练复盘 | 直接用光线和构图够好的实拍图（跑道、江边、终点、手持自拍实景），做三比例构图裁切 + 景深/调色/局部渐变暗角衬大字，保留真实临场感，不必强行抠图换假底 |
| **C. 装备 / 实物主视觉** | 聊装备、跑鞋实测、器材开箱 | 跑鞋/手表/相机特写、手持展示、新旧或双鞋分屏对比当主角（可带本人半身/手部同框），突出质感与细节 |
| **D. 核心数字 / 对比锚点** | 训练实验、数据复盘、成绩节点 | 把最抓眼的一个数字（如 `186`、`3:00`、`571km`）或前后对照做成视觉核心，人像或实景作辅助呼应 |

**出图数量**：方向明确时默认先出 1 版直接可用；想换风格或有两个不同视觉方向都挺有意思时，可以出 2 个明显区分的方案放 `cover-candidates/` 给用户挑。

## 工具与产出

**1. 使用 `compose_cover.py`（路线 A 快速排版，也可配合参数做变化）：**

```bash
.venv/bin/python tools/cover/compose_cover.py \
  --person ~/Movies/running-content/YYYY-MM-DD-slug/cover-work/person-cutout.png \
  --bg ~/Movies/running-content/YYYY-MM-DD-slug/cover-work/bg.jpg \
  --title "<封面句，可用 | 手动断行>" \
  --out-dir ~/Movies/running-content/YYYY-MM-DD-slug
```

- 可选变化参数：`--side left|right`、`--title-color R,G,B`、`--stroke-frac <浮点>`、`--series "<系列名>"`、`--font <字体路径>`、`--prefix cover-candidates/b-`。
- `--person` 可传已抠 RGBA PNG 或原自拍（有 `rembg` 用 rembg，否则尝试 `onnxruntime` + `~/.u2net/u2net.onnx`）。
- 字放不下会返回非零（退出码 2）：减字或用 `|` 断行，不接受偏小字号。默认只调脚本看退出码，改算法或排错时再读源码。

**2. 路线 B / C / D（实景、分屏、数字主视觉等）：**

可用 Pillow / ImageMagick / 轻量合成脚本或设计图 + 清晰大字排版，按三比例分别导出即可；记住仍要保证小图字号醒目且不重画人脸。

**3. 标准产出（分类目录输出到 `covers/`，旧平铺期写根，只产这三张正式图）：**

```text
covers/cover-4x3-1920x1440.jpg    # 4:3  横版  B 站首页推荐（biliup 唯一投稿封面）
covers/cover-3x4-1080x1440.jpg    # 3:4  竖版  小红书等
covers/cover-16x9-1920x1080.jpg   # 16:9 横版  B 站 / YouTube / 视频号
stills/                           # 存放自拍原图 / 参考图
cover-candidates/                 # 可选：多风格对比候选
```

写 `assets.md` 的 `cover: done` 并记所选版本与路径。`compose_cover.py` 会自动写 `cover` 墙钟；手做其它路线时用 `tools/log_timeline.py` 补记 `start cover` / `end cover`。

## 完成后

- 只换封面：停在这里，不用重拼成片。
- 还在成片主链：看 `assets.md` / `logs/todo.md`，`hud-record` 完成后推进 `/p3-assemble`；若预览已完成则回到当前所在阶段（如 `/p3-subs` 或 `final_export.py --confirmed`）。
