# 封面

封面流程：**拍摄单 → 自拍抠图 → 粗描边 → 创意底 → 三比例手排**。和 HUD 互不依赖，可在 `p3-hud` 渲染期间并行做。

## 封面原则

为本仓流程（手持自拍主体 + 抠图粗描边 + AI／设计创意背景 + 大字）定的原则。

在作者还是经验尚浅的 vlogger 阶段：**封面拍摄与封面成图都默认只给一条最优判断**，不列一堆变体让人选，不做 A/B。难得不确定时，最多「主推一条 + 备选一条」。

- **人出镜建立信任：** 封面必须有本人出镜（真人像素抠图，不重生脸）。
- **画面一眼能懂：** 主体动作和表情在手机小图上也能看清；不要靠细枝末节讲故事。
- **别点进去翻车：** 封面承诺和视频内容一致，不制造片子兑现不了的预期。
- **闭嘴 + 表情：** 用自然表情，不用刻意张嘴；表情比「说话状」更有冲击力。
- **背景简单、够跳、不抢字：** AI／设计底要简单、对比够强；主体抠出后融合不生硬；大字叠上去时背景不能抢字、不要残字／乱码。
- **封面文字要大、要醒目（硬性）：** 封面句是第一眼信息，在手机小图上必须「又大又清楚」。系列名「破三实验室」可以略小，但仍要可读。禁止中号、偏弱、塞在角落的字号；宁可少字、拆两行，也不要缩成文雅小字。对比要够（通常白字 + 深描边/阴影）。

## 前置

- 素材：选题阶段 `p3-topic` 给过「封面拍摄单」时，用用户按**那一条主推指令**拍的手持自拍（按需补拍，不要求凑多张变体）。没有就先请用户按拍摄单补拍；不要从成片 / HUD preview 抽糊帧凑数
- 封面句：该期定稿封面句；系列名「破三实验室」
- 封面句里的数字（心率、配速、成绩）**以 COROS/FIT 或口播核对过的数为准**（例：全马均心率写 186 不是口误的 187）

## 流程

1. **抠图：** rembg（或等效）抠出自拍里的真人像素，保留原始面孔
2. **粗描边：** 人物加**很粗的白描边**
3. **创意底：** 铺 AI／设计感背景（赛事夜景、粗粝夜跑、霓虹极简等）。遵循「简单、颜色够跳、手机小图可读」；主体放上去要融合自然；背景**不要残字 / 乱码**，也不要和前景大字抢视线
4. **大字（优先醒目）：** 前景大字 = 封面句关键词 + 系列名「破三实验室」。封面句字号要冲、占画面左半明显面积；拉开行距，别挤成一团。若小图上读不清，一律放大重排，不要靠「设计感」缩小字
5. **三比例手排：** 16:9 / 4:3 / 3:4 各自重排人物和大字位置，**不要把 16:9 naive crop 成 4:3 / 3:4**（会削头、切字）
**脚本（第 2、4、5 步固定下来，不要每期手搓）：** 抠好人像存 `cover-work/person-cutout.png`（RGBA）。也可以直接传原自拍：有 `rembg` 用 rembg，没有就用 onnxruntime + `~/.u2net/u2net.onnx`（10-22 那期的手抠法），都没有才报错，创意底存 `cover-work/bg.jpg`，然后：

```bash
.venv/bin/python tools/cover/compose_cover.py \
  --person ~/Movies/running-content/YYYY-MM-DD-slug/cover-work/person-cutout.png \
  --bg ~/Movies/running-content/YYYY-MM-DD-slug/cover-work/bg.jpg \
  --title "<封面句，可用 | 手动断行>" \
  --out-dir ~/Movies/running-content/YYYY-MM-DD-slug
```

脚本做粗白描边（`cover-work/person-outlined.png`）、三比例各自重排（横版人在右、字在左半；竖版字在上、人在下；`--side left` 反过来）、封面句白字深描边加阴影、系列名黄色约为封面句四成。**字号有硬下限**（横版 ≥ 画高 11%，竖版 ≥ 7.5%），放不下就报错，让你减字或用 `|` 多断一行，不会自动缩成中号字。断行只落在词边界（jieba）。每个比例打印「320px 小图字高」，有 `偏小` 就退出码 2，不要接受。只写文件，不打开图片查看器；要人看就把路径发给用户。要出备选用 `--prefix cover-candidates/b-`。

6. 先按最优判断出**一版**成图（难得才附一版备选）；需要对比时再放进 `cover-candidates/`，不要默认甩多版让人选

## 产出

**B 站要 16:9 + 4:3 两张**；小红书另要 3:4。

```text
cover-1920x1080.jpg          # 16:9  B 站个人空间 / 视频号（亦可 cover-16x9-1920x1080.jpg）
cover-4x3-1920x1440.jpg      # 4:3   B 站首页推荐（**规范像素 1920×1440**；`cover-4x3-1440x1080.jpg` 仅可选轻量）
cover-1080x1440.jpg          # 3:4   小红书（亦可 cover-3x4-1080x1440.jpg）
cover.jpg                    # 定稿别名，默认指向 16:9
cover-candidates/            # 仅在主推/备选需要并排时用
```

`assets.md` 制作状态写 `cover: done`（等人确认主推成图时可用 `cover: waiting-review`），并注明选用哪版与各比例路径。

## 不要做的事

- 不要用 HUD preview 当底图，数据条会进封面
- 不要用生图模型（GenerateImage 等）重画人脸当主角，身份会漂、越画越不像；只用抠出的真人像素合成（背景可以用 AI／设计图）
- 不要纯文字贴原自拍就当封面（用户觉得没价值）
- 不要在封面堆第二句鸡汤，背景里也不要塞装饰性乱字
- 不要把封面句做成中号/偏弱/角落小字；封面文字必须大且醒目
- 不要用糊帧、运动模糊的图当人物素材
- 不要为了换封面去重渲 HUD
