# 字幕初稿：校正反例与切条易错清单

初稿自检时按需加载。原则：**字必须跟嘴里说的走；切条只断开，不改字。**

## 校正反例

| 错误做法 | 错在哪 |
| --- | --- |
| 跑中随口报的配速、体感，整句删掉 | 信息被丢掉 |
| 长口语收成书面短句 | 指代和原表达被压缩 |
| 「完全」「什么」「其实」「大概」被润掉 | 口头禅也是原句 |

正确做法：原句留下；要断开就只改切分，不改字。

## 切条易错（交用户前必扫）

这是 **agent 人工职责**（脚本漏网或语义判断）。对照下面逐条改切分，不改嘴里说的字。改完切分后若已对过口型，再跑 `force_align.py`。

1. **不要把量词/后缀甩到下一行。** 「18-19」+「度了」→「18-19度了」；「2055」+「几」→「2055几」。单位、概数尾巴（度/几/公里/分/秒/% 等）跟它所修饰的数字同一条。
2. **优先短语边界。** 「太能冲了刷新了自己的PB」→ 两条：「太能冲了」/「刷新了自己的PB」。一句里两个完整谓语，宁可拆开。
3. **代词贴下一句主语。** 「之后的表现吧我 / 昨天…」错；对的是「看一下之后的表现吧」/「我昨天在看直播的时候」。
4. **语义单元别拆开。** 「精神 / 图腾吧」应并成「精神图腾吧」；双音节词组、专名、固定搭配同一条。
5. **用户点名重切后：** 改 `subtitles.txt` 切分 → `force_align.py` → `check_subs.py` → `txt_to_subs.py --media-dir auto`（会同步更新同名审片 `.srt`）。
6. **改刀点：** 只改 `logs/program.json`，再按新表重出预览和重对齐；不要只改预览文件制造隐藏 offset。冷开场和插入段只推成片时间，不改后面跑步段的原片对齐。
