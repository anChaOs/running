# 简介、抖音文案与平台标签规范

字幕人工确认（`subs: confirmed`）后写 `episodes/YYYY-MM-DD-slug/plan.md` 时按需加载。**只从校准后的 `subtitles.txt` 写**，不要按 `talk.md` / 选题卡硬套，也不要回改已发布旧期。

## 简介与抖音文案

覆盖 `plan.md` 占位（`### B 站`、`### YouTube`、抖音栏）：

- **极致压缩**：两三短句说清本期在干嘛即可，不要分段长摘要。口播明确引用了出处才写「参考」，否则不留这个标题。
- **B 站**：第一行 `个人视频制作来自：https://github.com/anChaOs/running`
- **YouTube**：第一行 `个人视频制作来自：github.com/anChaOs/running`（**不要 `https://`**）。整段（含参考）不能有任何 `http://` 或 `https://` 链接。
- **抖音**：不要 GitHub 行、不要「参考」。
  - **话题（最多 5 个）**：写成「建议话题」清单（不要可粘贴的 `#xxx` 整行）。优先国内抖音跑步圈热门标签，再按本期换贴题词；禁止把「破三实验室」等频道名当话题。

## 平台标签（`## 标签`）

与简介同一拍写入 `plan.md`（若无占位则新建整节 `## 标签`），不要抄旧期默认串：

```markdown
## 标签

B 站（5–8 个，不要堆）：

```text
#跑步 #马拉松 #跑步日常 ...
```

YouTube 标签：

```text
跑步, 马拉松, 跑步日常, ...
```
```

规则：

- **B 站**：**5–8 个**，空格分隔、带 `#`（投稿时 `/p3-bilibili` 去掉 `#` 改逗号传 `--tag`）。
- **YouTube**：**5–8 个**，逗号分隔、不带 `#`（`/p3-youtube` 的 `youtube_cloud.py` 自动解析该代码块）。
- 两边优先**重点、热点**（跑步圈常搜词），再按本期字幕补 1–3 个贴题词；**宁精勿冷门**，不堆小众专名或一期一过的梗。
- 禁止把「破三实验室」等频道名当标签；「破三」这类主题词可用。
- 抖音话题 ≤ 5；B 站 / YouTube 5–8 个。
