# 相对能量缺乏与骨应力

## 结论

能量可用不够时，骨头和内分泌先付账。【文献】LEA（低能量可用）指摄入能量相对运动消耗过低，余能不足以支撑生理功能；RED-S（Mountjoy 2018 IOC 更新）是相对能量不足相关的多系统表现受损综合征。碳水周期化如果叠加上总能量不足，不是「高级代谢训练」。

骨应力连续体（Warden 2014）必须查上游原因，训练突变和能量可用都在清单上。Heikura 2018：精英耐力选手中能量可用性（EA）很难精确评估；以生殖功能等代理区分时，功能异常组的骨相关损伤率显著更高（文中约 4.5 倍量级——摘要级，以原文为准）。

【口播-云健身】明胶/氨糖这类「护骨」补剂证据不足，不要当护身符；高蛋白伤骨说不成立（先保证钙），蛋白过少反而更伤骨。防伤主把手是负荷与力量，不是补剂柜。**硬边界：**疑似 LEA/RED-S 或骨应力 → 走运动医学/内分泌等专业路径；本页不展开诊疗路径或燃料处方。个体差异大，不是处方。

## 概念

| 概念 | 要点 |
|------|------|
| LEA | 低能量可用：摄入相对消耗过低，余能不足 |
| RED-S | Mountjoy 2018 IOC 更新：相对能量不足的多系统综合征 |
| 骨应力连续体 | stress reaction → stress fracture → complete fracture（Warden 2014） |
| EA 评估 | 测量噪声大；精英样本里也难精确 |

【文献】碳水周期化与 train-low 一节的减重、空腹叙事，必须和「总能量充足」分栏写。【口播-云健身】钙、能量、月经等系统因素属于临床范围，不靠氨糖替代减冲击；「酸性体质」长期说对健康人基本是伪科学（口播立场）。

【综合】本页加深点是把两条线接起来：LEA 相关结局 ↔ 骨应力 / 骨密度 / 损伤率。营养侧的补剂护骨叙事在这里降级为「不成立的默认假设」。

## 对训练的启发

个体差异大，不是处方。

- 骨应力相关笔记必须留「能量可用 / 月经–内分泌」检查框。这是转诊触发，不是自学诊疗。
- train-low、减重、赛季控体重，都要单列一栏写清总能量是否够；LEA 嫌疑时停止加压，而不是继续当代谢黑客。
- 复发性骨应力损伤提示必须查上游（负荷突变、能量、月经/内分泌、骨密度），不要「歇两周继续」。
- 自检一句话：是否指望氨糖、明胶代替减负荷？若是，先纠正这个假设。
- 疲劳、月经紊乱、反复骨痛、成绩持续掉 → 专业评估优先，不自行大剂量补铁或堆补剂。

## 待验证

- 复发骨应力损伤时，能量/月经/骨密度的转诊触发问题清单（非诊断）。
- EA 测量噪声大，因果方向需要前瞻研究。
- 女性、业余样本的外推边界；临床适应症下的处方不在本页范围。
