# 跑步相关损伤与负荷

> 学习与训练笔记，**非诊断、非治疗、非复跑处方**。个体差异大，不是处方。剧痛、骨痛夜痛、神经症状、锁定肿胀 → 合格临床人员。

## 结论

- 比较任何「跑步伤病 %」前先对齐 **RRI 操作定义**（Yamato 2015 娱乐跑者共识方向）；发生率跨度极大（van Gent 2007）。按每 1000 跑步小时：Videbæk 2015 加权约 **新手 17.8** vs **娱乐 7.7** /1000 h（摘要级；原研究约 2.5–33.0）。【文献】
- 【文献】Bertelsen 2017：伤可概念化为**结构特异负荷超过当时能力**（含课中能力下降）——多因素，非里程单因。
- 【口播-山雨】BV17：几乎所有伤病最终可归结到**过度训练（量×强度）+ 相关肌肉力量不足**；【口播-山雨】cv4928724：伤病大概率与跑量加太快或单次太快有关。【综合】与文献同向的部分是「负荷 vs 组织能力」匹配失败；「几乎所有」过强，两路分歧见待验证，本页不抹平。
- 【综合】常见伤的第一优先把手常是相关力量，而不是商业改姿课。同名疼痛可能对应不同组织。
- 【文献】ACWR 不作处方工具；负荷管理回到渐进暴露与个体反应。表上负荷比值也不是 OTS 诊断，见 [[过度训练与恢复]]、[[高驰负荷三个指标]]。

## 概念

### 负荷–能力模型

【文献】Bertelsen 四组件：(a) 进入课次时的结构特异能力；(b) 该次结构特异累积负荷；(c) 课次中能力下降；(d) 负荷超过能力。能力受既往伤、睡眠、能量可用、力量、表面/坡度等影响。

【口播-山雨】同一模型的口语版：

```text
外部负荷（量×强度×坡度×路面×鞋×体重…）
        ↓ 超过 ↓
组织能力（肌腱/肌力/骨/修复/既往伤…）
        ↓
症状 / 代偿 / 「坏跑姿」表象
把手：减尖峰 · 渐进暴露 · 针对性力量 · （必要时）临时改落地/步频/鞋 · 交叉保心肺
```

【综合】跑姿纠正 A→B 常带来新问题；许多坏姿态是肌力表象。同意「别迷信改姿治百病」，「力学完全无关」过强——见 [[肌腱病连续体与复跑]] 的再训练小节。

### 常见跑步伤与力量把手

【口播-山雨】BV17 训练笔记式整理，**非诊断**；口播自陈须结合自身。个体差异大，不是处方。

| 伤（口播叙事） | 优先想 | 跑姿/鞋备注 |
|----------------|--------|-------------|
| 跟腱 | 小腿力量；离心提踵/heel drops（中段 vs 止点不同）；≥数月量级 | 前掌更累跟腱；可试高落差 |
| 髌腱 | 大腿前后柔韧；离心（斜面蹲等） | 后掌或增风险→中/前掌或低落差 |
| ITBS | **髋外展**力量；非盲目「揉束」 | 臀下摆是弱的表现；上坡常减痛【口播-山雨】BV18 |
| 足底筋膜 | 减冲击/体重管理；伤期可提步频 | 慎极简/裸足 |
| 腘绳 | 补**臀**（含对侧） | 少怪「姿势」 |
| 小腿/胫区 | 小腿力量；落地方式 | 前掌→中后掌或减负 |
| 跑步膝 | 髋+大腿力量 | 改姿不如补力 |
| 骨应力 | 钙/能量/月经；减冲击；小腿 | 提步频；缓冲/trail；**须临床** |

【口播-山雨】肌腱命名「-itis」多为历史遗留，实质常纤维级物理损伤；ITBS 机制较信服「压迫邻近脂肪垫」叙事，纯摩擦说遭质疑。【文献】骨应力连续体（stress reaction → stress fracture → complete fracture，Warden 2014）须查上游：负荷突变、能量可用不足等；MTSS（Winters 2013）治疗研究偏倚高，难推特异「最佳疗法」；PFP（Crossley 2016）多因素，非单一软骨「磨损」叙事。各伤种离心组数与月数是口播叙事量级，不是处方。

### 伤期降负荷与交叉

【综合】+【口播-山雨】行动树：

```text
越跑越痛 / 骨痛夜痛 / 锁定肿胀 / 神经症状？
  ├─ 是 → 停冲击、临床评估（勿 run through）
  └─ 否（疑劳损）→ 降量或降强度 + 力量
        → 交叉保有氧（车/游/椭圆/水跑/开坡）
        → 能跑则常「保强度减量」（【口播-山雨】BV1384）
```

【口播-山雨】BV18：个人 *run through* 叙事 ≠ 通用医嘱。【口播-山雨】BV12V：跑的离心冲击使恢复慢 → 非冲击交叉减轻负担。伤期目标是保住有氧底座与神经肌肉，同时把组织尖峰负荷降到可适应范围；plyometrics 可在合适阶段保 power。**交叉不是偷懒，是负荷管理。** 具体伤种能否继续跑必须个体临床判断。

### ACWR 争议

【文献】ACWR（急性：慢性工作负荷比）在本批笔记中**仅作争议对读，不作处方工具**。主张侧（Gabbett 2016）：「更高负荷必更多伤」不完整；慢性负荷与体能也可能保护；训练不足亦可能增风险——观察关联为主，多为团队项目。批评侧（Impellizzeri 2020）：比值数学耦合、人为重分类、因果未立、预测增量有限；用人为固定/随机「慢性负荷」仍可得到类似损伤关联 → 呼吁 dismiss ACWR 理论用法。

【综合】本支柱立场：不写入「保持 ACWR 在 x–y」类结论；批评不否定「关注负荷突变」常识。训练–防伤悖论提醒：防伤讨论要纳入准备度/慢性基础，避免只谈减量。与 [[高驰负荷三个指标]] 的「负荷比值」是产品尺，不是同一个处方对象。

## 对训练的启发

个体差异大，不是处方。

- 用「负荷是否超过当前结构能力」提问，代替背伤名清单。读任何发病率数字前先问定义与人群；新手暴露管理更敏感。
- 对「某拉伸/某器械治愈」广告保持怀疑；拉伸/马克操防伤因果证据弱。
- 按部位选力量，而不是先买姿势课。近 2–3 周量或强度是否跳升？质量课是否过密？easy 是否伪装节奏？臀/髋外展/小腿本周是否有练？
- 伤期先分清红线 vs 劳损路径：红线不硬扛；劳损路径走行动树。骨应力疑似 → 临床红线，不在本页「练着看」。
- 负荷笔记回到渐进暴露与个体反应，而非比值区间。

## 待验证

- 【文献】Bertelsen 框架是多因素模型，明确不支持「几乎所有伤 = 过度训练 + 肌力不足」的单因总括；【口播-山雨】BV17 总模型接近后一句。两路并存：文献侧作病因框架，口播侧作训练自查语言，不互相抹平。
- 用 Yamato 定义回看流行病学：定义差如何改变发病率数字？
- ACWR 之后跑者负荷笔记保留哪些**非比值**指标？团队运动观察向跑步专项的外推边界？
- 与口播对照（非结论）：C7 负荷–能力框架部分支持，「几乎所有」需限定；C9 拉伸/马克操非防伤必须——部分支持；C10 个人 run through——负荷管理概念部分支持，个人协议无法检验。
