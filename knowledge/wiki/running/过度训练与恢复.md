# 过度训练与恢复

> 本页讲**恢复–应激的临床与共识概念**，不是手表/App 的产品读数。个体差异大，不是处方。**禁止自我诊断 OTS**；表现持续掉 + 恢复拉长 → 升级专业审查。

## 结论

- 【文献】Meeusen 2013 联合共识用**时间尺度 + 表现轨迹**区分 FOR / NFOR / OTS，**无单一金标准生物标志物**。业余跑者自我贴「OTS」标签风险高。
- 【文献】Kellmann 2018：系统监测恢复–应激，目标是最大化表现并预防 underrecovery、NFOR、OTS、伤病与疾病；方法需多模态、个体化。睡眠是恢复支柱之一（概念强）。
- 【第三方】手表上的「负荷比值 ≥150% 过度训练」是产品区间命名，**不是** OTS 诊断，见 [[高驰负荷三个指标]]。两把尺不能互相代替。

## 概念

### FOR / NFOR / OTS

| 术语 | 笔记要点 |
|------|----------|
| FOR | 表现短期↓，适当恢复后可反弹/超代偿 |
| NFOR | 表现↓持续更久；恢复需更长时间；尚未达 OTS |
| OTS | 长期表现↓ + 多系统症状；常为排除性；恢复可数月 |

【文献】区分靠的是表现轨迹和时间，不是某一次 HRV 或负荷比值。与 [[跑步相关损伤与负荷]] 的伤病线不同：OTS 是全身性恢复失衡，RRI 是局部结构过载；两者可同时出现，但不是同一个诊断。

### 恢复监测

【文献】Kellmann 2018：把睡眠、主观恢复、负荷放在同一监测叙事；多模态、个体化，不找单一神奇指标。Milewski 2014 青少年睡眠 &lt;8 h 与更高损伤报告相关——**关联 ≠ 个人因果证明**，非跑者专项。

【综合】日志里的升级触发写法：「表现持续掉 + 恢复拉长」才升级审查，而不是「今天表上红了」。

### 与产品尺的边界

| | 本页（共识概念） | [[高驰负荷三个指标]]（产品尺） |
|--|------------------|--------------------------------|
| 对象 | FOR / NFOR / OTS、underrecovery | 负荷比值、体力恢复、睡眠 HRV |
| 判据 | 时间尺度 + 表现轨迹 + 多系统症状 | App 给的百分比与区间文案 |
| 用途 | 何时停止自我实验、找专业人员 | 日常训练安排的参考读数 |
| 不能 | 手表读数不能诊断 OTS | 产品区间名不能当临床标签 |

## 对训练的启发

个体差异大，不是处方。

- 把睡眠、主观恢复、负荷放在同一监测叙事，但结论以表现轨迹为主。
- 日志里「表现持续掉 + 恢复拉长」才升级审查；禁止自我诊断 OTS。
- 与 [[跑步相关损伤与负荷]] 交叉：HIT 剂量上限要选「可恢复的组合」；伤期和 NFOR 边缘优先保恢复，不硬顶质量课。

## 待验证

- 耐力跑业余样本证据仍薄；跑者专项睡眠剂量反应仍薄。
- 业余环境里「表现持续掉」如何低成本测量（没有实验室）。
