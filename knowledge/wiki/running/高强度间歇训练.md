# 高强度间歇训练

## 结论

间歇得名于**恢复段**，不是得名于「跑得快」。【口播-山雨】（BV1pk4y167oM）按生理目的分五类：心肺 / 耐酸 / lactate reuse / clearance / aerobic resistance；**reuse 的休息必须 jog**，不能站停。心肺效果 ∝ 待在 ≥90% VO₂max 区的时间，实用 3–5′ 组或 30–60″ 短间歇，累计高强度约 **15–30′**。

最省事的可执行模板是**傻瓜间歇**：【口播-山雨】BV1XK411H74k（与【第三方】梨文 cv16277368 一致）单组 **5–8 min**、休息≈快跑一半的 **jog**、强度从 **10k** 起或 ~90%HRmax、累计高强度 **20–40 min**（新手先 20′）。马拉松向锚在 **LT～5k**，不必一味 VO₂max。

文献边界也要写清：【文献】HIT 对 VO₂max 有效，相对持续耐力多为**小幅额外增益**（Milanović 2015），不是数量级碾压。「HIIT 全面优于慢跑」在长期、伤病、依从与 TID 剂量上限维度不成立。间歇是对准短板的质量工具，不是越快越好——和 [[训练强度分布]] 里「大量 easy」是同一枚硬币的两面。

## 概念

### 按目的分类

| 目的 | 要点 | 来源 |
|------|------|------|
| 心肺（Cardiovascular） | 刺激越短越偏送氧、越长越偏用氧；效果∝≥90% VO₂max 区累计时间；实用 **3–5′** 或 30–60″ 短间歇；累计 **15–30′** | 【口播-山雨】BV1pk4y167oM |
| 耐酸 | 高强度反复，顶酸性环境 | 【口播-山雨】BV1pk4y167oM |
| Lactate reuse | 快跑约 LT **101–103%**，休息**必须 jog** | 【口播-山雨】BV1pk4y167oM |
| Clearance | 近 LT 刺激 + 约 **85% LT** 主动恢复；初学者常 10k 配速 | 【口播-山雨】BV1pk4y167oM |
| Aerobic resistance | 有氧阻力类 | 【口播-山雨】BV1pk4y167oM |

补充：

- LT 穷人估≈可维 **50–60′** 的最快配速（【口播-山雨】）。
- 心肺课压力大，常需 2–3 天恢复；非短板可 **2–3 周一次**。
- 慢肌/年长/易伤偏长间歇，快肌偏短间歇（【口播-山雨】）。
- 短/长间歇皆可，看**总高强度时间**（BV1VU4y1c7VL）。
- Sharpening 样例：10×800 @10k–5k，comfortably hard（BV1jL4y1z7LZ）——赛前磨刀，不是常年模板。

【第三方】梨文的五维课型排序（cv16277368/77428）可当提纲，与上面「按目的分类」**结构不同**，勿把梨文表标成口播总表（见 [[有氧能力提高]]）。

### 傻瓜模板参数

| 参数 | 主张 |
|------|------|
| 单组 | 5–8 min |
| 休息 | 快跑的 1/2，**jog** |
| 强度 | 10k 起 / ~90%HRmax |
| 累计高强度 | 20–40 min（新手先 20′） |
| 马向锚 | LT～5k，勿一味 VO₂max |

【口播-山雨】纯新手先慢跑积累；新手「10k 配速」常≈LT。【进阶】Thibault/MAP 曲线取点（例 `4×(7×90s)@85%MAP`）是设计工具，不是唯一正确；个体 MAP 测定不在本笔记。

质量课写清四件事：目标（心肺 vs reuse vs MP）；单组；休息方式（reuse 强制 jog）；累计高强度分钟。太快徒增疲惫时，先降锚回 LT～5k。

### 文献适应边界

【文献】Mølmen 2025（meta-regression）：线粒体内容相对↑ ET ~23%、HIT ~27%、SIT ~27%（组间 NS）；**单位训练小时效率**常 SIT ≫ HIT &gt; ET；毛细血管/mm² 更常见于 ET、部分 HIT。增益偏早期、偏初始体能较低者。成人 I 型比例改变通常有限——勿夸大「慢跑变慢肌」。

【文献】Milanović 2015（HIT vs 持续耐力 meta）：两者相对无运动都大幅提升 VO₂max；HIT 有小幅额外增益（约 +1.2 mL·kg⁻¹·min⁻¹ 量级的合并叙事，见公开摘要转述），基线低、干预更长者空间更大。**效应边界**：HIT 的「效率」叙事主要在 VO₂max，不等于全面支配跑步经济性、线粒体、毛细血管或伤病结局；同时要与「TID 里 HIT 占比有限、可恢复」一起记。

## 对训练的启发

- 先写清这节间歇抬的是哪一柱（VO₂max / 可持续分数 / RE，见 [[有氧能力提高]]），再定组次和配速。
- 需要可执行模板时用傻瓜模板，不要现场发明参数。
- 线粒体 ≠ 毛细血管，分指标选择课型。
- 基线体能低者 VO₂max 空间更大；已训者外推保守。
- 周里 HIT 次数受恢复约束，和 easy 底座一起排（[[训练强度分布]]）。

## 待验证

- 跑者 HIT 课次/周上限 × 非功能过度到达/伤病联合结局。
- SIT 单位小时效率 vs 长期伤病/依从/RE。
- Thibault/MAP 例题为示意，不在本笔记做个体测定。
