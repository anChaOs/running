## running

| 页 | 一句话 |
|----|--------|
| [[有氧能力提高]] | 五条通路是机制分解，Joyner 三柱是表现公式，对照着用不合并 |

| [[跑姿步频与姿势跑法]] | 勿迷信 180 与姿势跑法；自然跑姿 + 力量/strides 优先 |
| [[Fatmax与脂肪氧化]] | 强度↑糖占比↑；「30 分钟才耗脂」不成立；Fatmax 勿神化 |
| [[碳水周期化与train-low]] | 训可调、赛要高；train-low 机制与成绩证据分开记 |
| [[耐力赛能量补充]] | 赛中补糖共识级：单源约 60 g/h，混合糖才谈约 90 g/h 且 >2.5h |
| [[日常能量与吸收]] | TDEE 量级估对；4-4-9 已含吸收约定；「多吃不胖=吸收差」通常错 |
| [[相对能量缺乏与骨应力]] | LEA/RED-S 是骨应力上游；护骨补剂证据不足 |
| [[跑步相关损伤与负荷]] | 伤≈负荷超过当时能力（多因素）；ACWR 只作争议对读 |
| [[肌腱病连续体与复跑]] | 负荷可双向调节；复跑按组织暴露，力量记忆≠冲击耐受 |

| [[停训与复训]] | 慢积慢失；跑步恢复更难常因离心冲击 |
