# HUD v2 优化目标

画布：1920×1080。样本：`2026-04-23-first-video/2026-04-23-run-a.mp4`（该期没有 HUD 成片，用当前默认模板占位框叠上去）。对照成片：`2026-04-27-run-b-hud.mp4`（旧右上角地图版）。

视觉主线已落地。其后增量：地图去掉底框只留路线；进度条深槽 + 暖白填充；定位点改白瓷点；右下用天气替换 GPS（`°C / °C`，湿度单独一行）。操作说明见 `tools/hud/README.md`。

## 问题

1. **挡主体。** `run-a` 是低机位路面前方视角，画面主体是路面和消失点。当前默认左下 / 右下各 250×250 不透明块正好压在路上。左上再占 250×250，内容却只有鞋名和时钟，空盒过大。
2. **挡字幕。** 左下主指标和右下地图都落在底部 160px 字幕带里。剪映加字幕会和配速、地图打架。
3. **竖屏中裁会裁掉 HUD。** 16:9 取中间 9:16（约 x=656–1264）后，左右模块全部出画，顶栏也被切掉一半。现在的四角布局只服务横屏。
4. **边距和对齐不统一。** 顶 28、左 40、左下底边距 70、右下底边距 40；左下 y=760、右下 y=790，底边不齐。04-27 成片里顶栏又偏左一截，和左右模块不在同一网格上。
5. **没有重点。** 配速、心率、步频字号接近；鞋里程 `2143.50 km` 和配速抢视线。地图只有淡轮廓，背景一复杂就读不出来。
6. **进度条不好看。** 左右各一个公里数，中间一条细线；轨道和填充对比弱，没有滑块，不像「跑到哪了」，像一条装饰。
7. **生产和文档漂移。** 仓库默认已是 map-safe（地图右下），04-27 成片仍是右上角 `ROUTE` 地图，正打在平台水印区。

## 设计原则

1. 主体（路面消失点、人脸）不放不透明块。
2. 底部中央留字幕带，HUD 不进这条带。
3. 右上平台水印区留空。
4. 同一套边距、同一条齐线，模块高度按内容收，禁止为了「四个角对称」撑出空盒。
5. 一个重点：配速。心率、步频跟配速；进度在顶栏；地图左上；鞋和时间右下。
6. 进度条要能一眼读出「已经跑了多少 / 这场还剩多少」。

## 网格（16:9）

- 边距 **40px**，模块间距 **16px**。
- 字幕带：`y=920–1080`，全宽留空。
- 水印区：右上约 `240×88`，留空。
- 顶栏：水平居中，`y=40, h=64, w=860`（`x=530`），当前 km + 胶囊进度 + 总 km。配色褐土·沙。
- 左上地图：`x=40, y=40, w=220, h=108`，无 ROUTE。
- 左侧腰：`x=40, y=164, w=220, h=100`，配速 `6'15"` 最大，其下 bpm / spm。
- 右侧腰：`x=1660, y=164, w=220, h=64`，与左顶对齐；鞋名+里程，时间+日期。
- 模块高度按内容收，禁止 250 空盒。不进字幕带，不压下三分之一路面。

## 层级

| 层级 | 内容 | 形态 |
|------|------|------|
| 重点 | 配速 | 最大数字，单位 `/km` |
| 侧腰 | 心率、步频 | 配速下方，约一半字号，弱标签 `HR` / `CAD` |
| 叙事 | 距离进度 | 顶栏：当前 km + 条 + 总 km |
| 弱 | 地图、鞋、时间 | 小、静、不跟配速抢对比 |

## 进度条

- 一条胶囊轨道，高 8–10px，填充和轨道对比明确。
- 当前进度有圆点或短滑块，不要只靠颜色差。
- 左侧当前距离、右侧本场总距离；不要再各放一套重复的大数字。
- 总距离继续由 FIT 写入 `max`，脚本已有，保持。

## 明确不做

- 不把 9:16 中裁当成这一轮的硬约束。竖屏若要带 HUD，另做一版顶栏模板，不把四角模块硬塞进竖屏。
- 不给 `open` / `close` 叠 HUD。
- 不恢复右上角地图。
- 不增加海拔、卡路里、功率。
- 不改 FIT 对齐逻辑。

## 验收

用 `2026-04-23-run-a` 渲一版短样（不必整段）检查：

1. 路面消失点附近没有大块面板。
2. 底部中央 160px 没有 HUD。
3. 右上水印区没有 HUD。
4. 顶栏水平居中；地图在左上；配速心率在左下；鞋和时间在右下。左右边距 40。
5. 配速是画面里最大的数据；鞋里程明显更弱。
6. 进度条在树荫和亮地面上都能看出填充。
7. 和 04-27 旧成片比：不再出现右上 `ROUTE`。
