# 素材与命名

大文件不进仓库。原始视频、FIT/GPX、HUD 工程、成片统一放在：

```text
~/Movies/running-content/YYYY-MM-DD-topic/
```

`topic` 用短英文或拼音，并与 `episodes/YYYY-MM-DD-topic/` 对齐。

仓库里只保留该期 `episodes/.../assets.md`：本地目录、原文件名映射、剪辑备注。

## 视频

- `YYYY-MM-DD-open.mp4`：最早一条，跑前
- `YYYY-MM-DD-run-a.mp4`、`run-b`、`run-c`：跑中，按时间顺延 `run-d`
- `YYYY-MM-DD-close.mp4`：最晚一条，跑后
- `YYYY-MM-DD-broll-01.mp4`：空镜

## 数据与成片

- `YYYY-MM-DD-run-data.fit`（优先高驰 MCP 拉取）
- `YYYY-MM-DD-stats-01.jpg`：高驰训练截图（叠到 close 左侧）
- `weather-hourly.json`：天气缓存
- `logs/`：`program.json`（时间表）、`todo.md`（进度门闩）、`timeline.txt`（墙钟）、`failures.md`、`pack-sha256.txt`、`youtube-upload-result.json`
- `YYYY-MM-DD-review-preview.edl`：审片播放清单（清临时保留）
- `hud-renders/`：HUD 透明层（`qtrle/*-hud-alpha.mov`，清临时可删）
- `asr/`、`qc/`、`cover-work/`：转写、抽帧核对、封面工作中间产物（清临时可删）
- 最终成片（导出）：`YYYY-MM-DD-run-final.mp4`（`final_export.py --confirmed` 输出）；打包进 `upload/` 后改名为 `<标题>.mp4`
- 封面（比例在前）：`cover-4x3-1920x1440.jpg`、`cover-3x4-1080x1440.jpg`、`cover-16x9-1920x1080.jpg`
- `upload/`：发布打包目录（唯一成片 + 三封面 + 外挂 `subtitles.srt`）
- `publish-report.html`：发布单屏报告（并同步至 Google Drive `running-retrospect/`）

## 每次收素材

手机未重命名导出（`VID_YYYYMMDD_HHMMSS.mp4`）走 skill `p3-ingest` / `tools/ingest/ingest_run_media.py`。先 dry-run 对角色，再 `--apply`。

1. 大文件进 `~/Movies/running-content/YYYY-MM-DD-topic/`
2. 按拍摄时间改成 `open` / `run-*` / `close`
3. FIT 改成 `YYYY-MM-DD-run-data.fit`
4. `VID_` 的文件名是开始时间；`mtime` 必须能当结束时间（开始 + 时长），否则 HUD 会对不齐
5. 在对应 `episodes/` 目录写或更新 `assets.md`（含制作状态）
