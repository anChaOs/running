# 素材与命名

大文件不进仓库。原始视频、FIT/GPX、HUD 工程、成片统一放在：

```text
~/Movies/running-content/YYYY-MM-DD-topic/
```

`topic` 用短英文或拼音，并与 `episodes/YYYY-MM-DD-topic/` 对齐。

仓库里只保留该期 `episodes/.../assets.md`：本地目录、原文件名映射、剪辑备注。

## 视频

- `YYYY-MM-DD-open.mp4`：最早一条，跑前
- `YYYY-MM-DD-run-a.mp4`、`run-b`、`run-c`：跑中，按时间顺延 `run-d`
- `YYYY-MM-DD-close.mp4`：最晚一条，跑后
- `YYYY-MM-DD-broll-01.mp4`：空镜

## 数据与成片

- `YYYY-MM-DD-run-data.fit`
- `YYYY-MM-DD-run-data.gpx` / `.png`：需要时再导出
- HUD 默认输出：`<素材目录>/hud-renders/`
- 天气缓存：`weather-hourly.json`
- 转写：`asr/`
- 成片核对帧：`qc/`
- 成片如需本地归档：`YYYY-MM-DD-run-final.mp4`（`assemble_episode.py` 默认文件名）
- 封面：`cover-1920x1080.jpg`、`cover-1080x1440.jpg`

## 每次收素材

手机未重命名导出（`VID_YYYYMMDD_HHMMSS.mp4`）走 skill `p3-ingest` / `tools/ingest/ingest_run_media.py`。先 dry-run 对角色，再 `--apply`。

1. 大文件进 `~/Movies/running-content/YYYY-MM-DD-topic/`
2. 按拍摄时间改成 `open` / `run-*` / `close`
3. FIT 改成 `YYYY-MM-DD-run-data.fit`
4. `VID_` 的文件名是开始时间；`mtime` 必须能当结束时间（开始 + 时长），否则 HUD 会对不齐
5. 在对应 `episodes/` 目录写或更新 `assets.md`（含制作状态）
