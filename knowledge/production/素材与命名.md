# 素材与命名

大文件不进仓库。原始视频、FIT/GPX、HUD 工程、成片统一放在：

```text
~/Movies/running-content/YYYY-MM-DD-topic/
```

`topic` 用短英文或拼音，并与 `episodes/YYYY-MM-DD-topic/` 对齐。

仓库里只保留该期 `episodes/.../assets.md`：本地目录、原文件名映射、剪辑备注。

## 分类目录布局（新期默认，工具同时向下兼容平铺旧期）

```text
~/Movies/running-content/YYYY-MM-DD-topic/
  raw/       YYYY-MM-DD-open.mp4、run-a/b/c.mp4、close.mp4、broll-01.mp4
  data/      YYYY-MM-DD-run-data.fit（优先高驰 MCP 拉取）、YYYY-MM-DD-stats-01.jpg、weather-hourly.json
  stills/    自拍原图及静态参考图
  covers/    cover-4x3-1920x1440.jpg、cover-3x4-1080x1440.jpg、cover-16x9-1920x1080.jpg
  preview/   YYYY-MM-DD-review-preview.edl（校对期间 sidecar .srt）
  upload/    发布打包目录（唯一成片 <标题>.mp4 + 硬链三封面 + 外挂 subtitles.srt）
  logs/      program.json、todo.md、timeline.txt、failures.md、pack-sha256.txt、youtube-upload-result.json
  publish-report.html   发布单屏报告（并同步至 Google Drive running-retrospect/）
```

生产期间另有临时目录 `hud-renders/`、`asr/`、`qc/`、`cover-work/`（发布确认后移入废纸篓）。最终导出在打包前暂落根目录 `YYYY-MM-DD-run-final.mp4`，改标题后由 `pack_upload.py` 移入 `upload/`。

## 每次收素材

手机未重命名导出（`VID_YYYYMMDD_HHMMSS.mp4`）走 skill `p3-ingest` / `tools/ingest/ingest_run_media.py`。先 dry-run 对角色，再 `--apply`。

1. 大文件进 `~/Movies/running-content/YYYY-MM-DD-topic/`
2. 按拍摄时间改成 `open` / `run-*` / `close`
3. FIT 改成 `YYYY-MM-DD-run-data.fit`
4. `VID_` 的文件名是开始时间；`mtime` 必须能当结束时间（开始 + 时长），否则 HUD 会对不齐
5. 在对应 `episodes/` 目录写或更新 `assets.md`（含制作状态）
