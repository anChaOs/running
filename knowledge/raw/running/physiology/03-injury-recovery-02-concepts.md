# 关键概念 / 机制 · 伤病与恢复

更新日期：2026-09-22（Asia/Shanghai）  
读法：先分清「定义」与「证据强度」；争议点勿写成定论。  
**边界：** 概念笔记，**非诊断标准、非治疗/RTS 处方**。疼痛或功能障碍 → 寻求合格临床人员。

---

## 1. 跑步相关损伤（RRI）

| | |
|--|--|
| **English** | Running-related injury (RRI) |
| **操作定义（娱乐跑者共识方向）** | Yamato et al. (2015)：与跑步训练/比赛相关的肌肉骨骼疼痛，导致跑步量减少 ≥7 天、或需医疗、或需用药/辅具等（以原文条目为准；笔记时逐条核对） |
| **强** | 比较流行病学前必须先对齐定义；「每 1000 跑步小时」比粗「% 受伤」更利于跨研究（Videbæk 2015） |
| **争议 / 局限** | 研究间定义、随访、人群（新手/娱乐/越野/田径）异质 → van Gent 2007 已显示发生率跨度极大；共识未被所有后续研究采用 |

## 2. 负荷–能力匹配（load–capacity）

| | |
|--|--|
| **English** | Structure-specific load vs capacity |
| **框架（Bertelsen 2017）** | 进入一次跑步时的结构特异能力；该次累积负荷；过程中能力下降；负荷超过能力 → 损伤事件概念化 |
| **强** | 把「过度使用」改写成可检验的剂量–反应与可修饰暴露；与渐进暴露逻辑相容 |
| **争议** | 「能力」难直接测量；生物力学代理 ≠ 组织真实耐受；个体差异大 |

**笔记提醒：** 能力受既往伤、睡眠、能量可用、力量、表面/坡度等影响——多因素，不是里程单因。

## 3. 肌腱病连续体（tendinopathy continuum）

| 阶段（2009 模型语言） | 粗含义（笔记用） |
|----------------------|------------------|
| Reactive | 急性过载后细胞驱动的腱适应/肿胀叙事 |
| Tendon disrepair | 修复尝试失败、基质紊乱加重 |
| Degenerative | 局部退变区域；可与相对「安静」疼痛表现并存 |

- **English：** Continuum model of tendon pathology（Cook & Purdam 2009；Cook et al. 2016 再访）  
- **强：** 提供「减量 ≠ 永久静止、负荷可调节病理方向」的教学框架；推动离心/慢速抗阻等负荷路径研究。  
- **争议：** 主要是**疼痛**病，结构分期与疼痛/功能不完全对齐（2016 文明确讨论）；影像≠必须临床分期工具。  
- **跟腱中段 RTS：** Silbernagel & Crossley (2015) 描述分阶段暴露与重负荷间隔逻辑——**文献方案叙事，不是本目录处方**。  
- **负荷 RCT 例：** Beyer 2015 — ECC 与 HSR 12 周临床结局相近，依从/满意度或有利于 HSR。

## 4. FOR / NFOR / OTS

| 术语 | English | 笔记要点（共识语言） |
|------|---------|----------------------|
| 功能性过度到达 | Functional overreaching (FOR) | 表现短期↓，**适当恢复后**可反弹/超代偿 |
| 非功能性过度到达 | Nonfunctional overreaching (NFOR) | 表现↓持续更久；恢复需更长时间；尚未达 OTS |
| 过度训练综合征 | Overtraining syndrome (OTS) | 长期表现↓ + 多系统症状；诊断困难，常为排除性；恢复可数月 |

- **挂点：** Meeusen et al. (2013) 联合共识。  
- **强：** 用**时间尺度 + 表现**区分，而非单次乳酸或一次 HRV。  
- **争议 / 局限：** 无单一金标准生物标志物；业余跑者自我贴「OTS」标签风险高 → 升级专业评估。  
- **监测接口：** Kellmann et al. (2018) — 系统监测恢复–应激以预防 underrecovery / NFOR（工具多样，个体化）。

## 5. 重返运动（RTS）— 概念级

- **English：** Return to sport / return to running  
- **文献中常见元素（描述性）：** 症状与功能基准 → 行走/日常负荷耐受 → 慢跑暴露 → 速度/坡度/专项 → 比赛；伴随力量与心理 readiness（因伤而异）。  
- **强：** 「阶梯式暴露 + 监控反应」是跨伤种的共通逻辑。  
- **争议：** 具体疼痛阈值、周进度、影像愈合标准因伤种与个体而异；**本目录不给出可执行处方**。  
- **跟腱例：** 见 Silbernagel 2015 笔记（B 区）——仅摘文献描述。

## 6. 步态再训练（running / gait retraining）

| | |
|--|--|
| **常见操纵** | 步频↑、步幅↓、着地方式、躯干/髋策略、反馈（镜子、可穿戴） |
| **机制层（强）** | Heiderscheit 2011：偏好步频 ±5–10% 改变髋膝能量吸收等力学（健康受试者实验） |
| **临床层（谨慎）** | Barton 2016：即时力学证据较多；**伤者临床 RCT 当时仍有限**；专家意见填空需标明 |
| **争议** | 改一处力学常转移负荷；「万能 180 spm」无共识支持；应服务于临床目标而非审美 |

## 7. 急性：慢性工作负荷比（ACWR）— **争议工具**

| | |
|--|--|
| **主张侧（Gabbett 线）** | 「训练–防伤悖论」：过低慢性负荷也可能不利；相对尖峰与损伤关联在多项队运动观察中被报告 |
| **批评侧（Impellizzeri 等）** | 比值数学耦合、人为重分类、因果未立、预测增量有限 → 呼吁 dismiss ACWR 理论用法 |
| **本支柱立场** | **仅作争议文献对读**；不写入「保持 ACWR 在 x–y」类笔记结论；负荷管理仍回到渐进暴露与个体反应 |

## 8. 常见跑者伤类（概念卡片入口）

### 8.1 骨应力损伤（BSI）
- **连续体语言（Warden 2014）：** stress reaction → stress fracture → complete fracture。  
- **强：** 反复负荷超过骨修复；复发率高提示须查上游原因（训练突变、生物力学、**能量可用/三联征–RED-S**）。  
- **争议 / 边界：** 高风险部位 vs 低风险部位管理差异属**临床**范畴；本目录只保留概念与文献挂点。

### 8.2 MTSS（胫骨内侧应力综合征）
- **Winters 2013：** 治疗研究偏倚高，难推出特异「最佳疗法」；负荷管理与力量在临床上常被逻辑性强调（≠高等级证据证明唯一方案）。

### 8.3 PFP（髌股疼痛）
- **Crossley 2016 共识 Part 1：** 术语、定义、检查与自然史框架；强调定义清晰与 PROMs。  
- **强：** 多因素（负荷、力量、运动控制等），非单一软骨「磨损」叙事。  
- **勿写：** 未经核实的胶带/鞋垫万能结论。

## 9. 睡眠与恢复监测（损伤风险语境）

- **观察例：** Milewski 2014 — 青少年运动员睡眠 <8 h 与更高损伤报告相关（关联 ≠ 个人因果证明）。  
- **共识：** Kellmann 2018 — 监测恢复以最大化表现、降低 underrecovery / NFOR / 伤病疾病风险；方法需多模态、个体化。  
- **强 / 弱：** 睡眠是恢复支柱之一（概念强）；跑者专项因果链与剂量反应仍薄。

## 10. LEA / RED-S / 女运动员三联征 — 与骨/伤病接口

| 概念 | 笔记位置 |
|------|----------|
| LEA / RED-S 定义、健康–表现模型 | **主挂支柱 02**（Mountjoy 2018 等） |
| 本支柱加深点 | LEA 相关结局 ↔ **骨应力 / 骨密度 / 损伤率**（Heikura 2018：精英耐力选手生殖功能异常组骨伤率更高量级） |
| **强** | 低能量可用是骨应力复发叙事中必须检查的上游假说之一 |
| **边界** | 不在此展开燃料细节或诊疗路径；疑似 → 运动医学/内分泌等专业路径 |
