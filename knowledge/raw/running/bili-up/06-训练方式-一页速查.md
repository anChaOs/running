## 记住这一句

**【综合】** 周计划 = **大量真 easy** + **少而写清的质量课** + **可恢复的长距离** +（可选）**短上坡/strides/力量**。

---

## Easy（【UP专栏】cv4928724）

| 规则 | 要点 |
|---|---|
| 占比 | 高跑量/马拉松周期 **≥70–75%** mileage easy |
| 衡量 | easy 用**时间**（≥~30′ 有意义；本人常 ≤90′）；workout 用距离 |
| 间隔 | 质量课之间 ≥1 easy day |
| 配速锚 | 能聊天 / MAF / %HRmax / %5k |

---

## 傻瓜间歇（【UP BV1XK】+【梨】）

| 参数 | 值 |
|---|---|
| 单组 | **5–8 min** 快跑 |
| 休息 | 快跑的 **1/2** jog |
| 强度 | **10k** 起，或 ~90%HRmax |
| 累计 | 高强度 **20–40 min**（新手先 20′） |

马拉松：间歇锚在 **LT～5k**，勿一味 VO₂max。【进阶】Thibault/MAP 曲线取点（例 4×(7×90s)@85%MAP）。

---

## 马拉松课型速记

| 来源 | 模板 |
|---|---|
| 【BV1zq】唠嗑课例 | ~5k 热身 → **3 mile @MP–HMP** → 休 → **6×1k**（HMP→10k）+400 jog |
| 【BV1of】周期 | LSD **隔周加长**；中间周 75–90′；短周末可渐进到 MP；力量前多后少 |
| 【BV147】周记样例 | easy+短坡 / 1′上坡 / 中距离 / 恢复 / MP 渐进 / 恢复 / 变速+MP（个人 sub240 周） |
| 【BV1VU】长距离 | 口播倾向 ~**2–2.5 h** 卡时长（经验） |

---

## 上坡 / strides

| 课 | 【UP】要点 |
|---|---|
| 8–15″ 短上坡 | 近最大努力；**走下坡充分休**；6–10 组；勿加长/减休【BV1d/BV1yM】 |
| 30–90″ | 送氧；10k–5k effort |
| ~3′ 长上坡 | 用氧；可代部分力量【BV1yM】 |
| strides | 质量前 **2–3×60–80 m**【BV1x】 |

---

## 周期骨架【综合】+【BV19b Lydiard 叙事】

`有氧地基 → 阈值/专项 → sharpening(如800) → 减量`  
夏训：恢复慢 → 保刺激时常**降强度或拆分**【BV1dg】。

---

## 力量接口【云健身】

| 题 | 一句 |
|---|---|
| 动作速度 | 重负荷自然慢；**勿刻意慢推当增肌魔法**【BV1Wd】 |
| 女跑者 | 注意腘绳/股四平衡与落地控制；ACL 风险叙事更高【BV19d】 |
| 平台期训练 | 查负荷；常用 **6–12RM**，可试 ~8RM；换动作勿过频【BV19j】 |
| 平台期营养 | 热量先够（可试 +10–15%）；蛋白约 **1.4–1.8 g/kg** 量级转述【BV1XJ】 |

跑者力量目标常是防伤/经济性，不是纯增肌最大化。

## 文献锚

Seiler 强度分布｜Joyner 表现｜Hughes 力量适应｜Llanos-Lagos 力量≠必然改 VO₂max

## 自检清单

- [ ] easy 是否伪装成节奏  
- [ ] 质量课是否写清：目的/锚/休息/累计高强度  
- [ ] 质量之间是否有真恢复日  
- [ ] 长距离是否无限拉长「为了意志」  
- [ ] 短上坡是否休息不够导致动作崩  
- [ ] 夏训是否硬打强度导致连续疲劳  
- [ ] 力量是否只追泵感/慢动作而忽视负荷  
- [ ] 是否把 UP 个人周记/配速当自己的处方  

**口诀：** 真 easy · 少而清的质量 · 可恢复的长距离 · 短坡充分休 · 力量服务跑步 · **笔记≠处方** · 证据分栏。
