## 常见伤 → 第一把手（【UP口播】笔记向）

| 伤 | 优先想 | 跑姿/鞋备注 |
|---|---|---|
| 跟腱 | 小腿力量；离心提踵/heel drops（中段 vs 止点不同）≥数月量级 | 前掌更累跟腱；可试高落差 |
| 髌腱 | 大腿前后柔韧；离心（斜面蹲等） | 后掌或增风险→中/前掌或低落差 |
| ITBS | **髋外展**力量；非盲目「揉束」 | 臀下摆是弱的表现；上坡常减痛【BV18】 |
| 足底筋膜 | 减冲击/体重管理；伤期提步频 | 慎极简/裸足；中后掌或稳 |
| 腘绳 | 补**臀**（含对侧） | 少怪「姿势」 |
| 小腿/胫区 | 小腿力量；落地方式 | 前掌→中后掌或减负 |
| 跑步膝 | 髋+大腿力量 | 改姿不如补力 |
| 骨应力 | 钙/能量/月经；减冲击；小腿 | 提步频；缓冲/trail；**须临床** |

## 伤期行动树（【综合】+【UP】）

```
越跑越痛 / 骨痛夜痛 / 锁定肿胀 / 神经症状？
  ├─ 是 → 停冲击，临床评估（勿 run through）
  └─ 否（疑劳损）→ 降量或降强度 + 力量
        → 交叉保有氧（车/游/椭圆/水跑/开坡）
        → 能跑则常「保强度减量」【交叉 BV1384】
```

**【UP BV18】** 个人 *run through* 叙事 ≠ 通用医嘱。

## 复训（【云健身 BV146】+【文献】）

- 力量：约 4 周内向心常还在；8–12 周或仅掉约 7–12%；**有记忆，复训斜率陡**。  
- 跑的冲击耐受 ≠ 杠铃还能推 → 对齐肌腱 RTS（Silbernagel）：渐进暴露。  
- 复训早期蛋白/热量可略增（口播 +0.3–0.5 g/kg、+300–500 kcal 仅参考）。

---

## 补剂 / 骨（【云健身】谨慎）

- 明胶 / 氨糖：**证据不足**，勿当护身符【BV1B】。  
- 高蛋白伤骨说：**不成立**（先保证钙）；蛋白过少更伤骨【BV1kM】。  
- 「酸性体质」长期说：健康人基本伪科学。
