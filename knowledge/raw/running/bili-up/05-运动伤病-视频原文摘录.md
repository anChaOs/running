## 山雨小月

### BV17i4y187vb · 伤病成因以及预防（CORE）
- URL：https://www.bilibili.com/video/BV17i4y187vb  
- 字幕：AI，近完整（文件约 **15336** 字）｜理论来源口播：**坤帅** + 本人理解｜接 BV1N 跑姿篇

**要点**
1. 无人保证不受伤；遇伤找靠谱医生；授人以渔做系统介绍。
2. 几乎所有伤 → **过度训练 + 相关肌力不足**；可持续加量是「内功」。
3. 跑姿造成不同力学，但纠正 A→B 常带新问题；坏姿态多是肌力表象。
4. 三大类：肌腱韧带 / 肌肉 / 骨。

**肌腱韧带**
- **跟腱：** 中段 vs 止点；多非炎症而是纤维损伤；储能弹簧；**前掌**更易累及；高落差鞋可助后掌；小腿力量；中段台阶提踵、止点 flat eccentric heel drops；例 1日×3组×15，≥3 月。
- **髌腱：** 材料类肌腱实为韧带；跑步破坏性常不如球类；相关因素口播强调大腿前后**柔韧性**；后掌或增风险→可试中/前掌或低落差；斜面深蹲离心。
- **ITBS：** 摩擦说遭质疑 → 压迫富神经血管脂肪垫；屈膝 20–30° 最痛；相关度最高**髋外展无力**；补力量后姿态自消，不必主动改姿。
- **足底筋膜：** 久站/走/跑皆可；蹬地时相伤害常更大；晨痛=夜间修复后首步再损；体重/冲击/年龄；足弓高低证据弱；伤期提步频；前掌/极简/裸足对弱筋膜不利。

**肌肉**
- 腘绳：臀弱代偿；可对侧臀弱致本侧伤。
- 小腿/胫骨区部分：着地+蹬地；前掌改中后掌或有助；增小腿力量。

**骨相关**
- 跑步膝：滑动轨迹叙事；软骨未必已损；髋大腿弱是本质；女生更易；柔韧差或需膝代偿。
- 半月板：口播称跑中几乎可忽略；马 MRI 叙事未见不良；少大下坡、提步频、关节周力量。
- 应力骨折：超自愈的冲击；骨密度/冲击史/小腿肌/性别与月经；补钙勿过度节食；提步频；后→前掌减胫骨冲击；缓冲鞋与 trail。

**选摘**
> 「几乎所有的伤病其实到最后都能归结到过度训练，而你的相关肌肉力量不足。」  
> 「如何保证无伤的持续的训练才是内功。」  
> 「如果你真的遇到了跑步相关的伤病，找一个靠谱的医生比什么都好。」

### BV18Q4y1i7pp · 我如何面对跑步伤病
- URL：https://www.bilibili.com/video/BV18Q4y1i7pp  
- 字幕：AI（文件约 **5197** 字）；后半交叉训练实拍+歌词，方法论在片头

**要点**
1. *run through*：降量/降强度 + 加强力量过渡；自称多数跑步伤未停跑、未拖成长期妨碍。
2. 大跑量（例周期至约 80 mile/周）+ 绝大部分慢跑；稍不适就改 workout→easy；体感**完全休息不如降强度**。
3. 交叉：游、水中挪动、车、椭圆、楼梯机、跳绳；ITBS 用**上坡/跑步机开坡**减痛。
4. 饮食：碳水依赖 + 有意识加蛋白；不吃补剂；质量/长距离后立刻补。
5. 拉伸因伤种而异；本人跑后 5–10′；归根力量不足；自重力量 1–3×/周；上坡可部分代力量。
6. 收尾鸡汤：「在等待的日子里，刻苦读书，谦卑做人，养得深根，日后才能枝叶茂盛。」

**选摘**
> 「我个人的体会是完全休息不如降强度，对身体伤病的恢复意义更大。」  
> 「伤病的发生最终就是因为你的量或者是你的强度太大，而你的力量不足。」

### BV1o7411F77p · 跑后拉伸（个人习惯九动作）
- URL：https://www.bilibili.com/video/BV1o7411F77p  
- 字幕：AI（约 **2338** 字）

**要点**
1. 科学无定论；只分享习惯（GARMIN 营 + 他人经验）。
2. 九动作×约 15–30″/侧：小腿 → 股四 → ITB/外侧 → 腘绳勾尖 → 臀+后侧 → 内收侧伸 → 坐姿脚掌相对 → 抱膝压臀 → 髂腰肌。
3. Easy 后可直接拉；workout/long/赛后先冷身补剂再轻拉，或晚间 recovery 后再拉。

**选摘**
> 「至于拉伸好不好，不拉伸有无坏处，至今科学界也无定论。」

### BV1xF411h7zr · 冬季跑步热身（结论适用于四季）
- URL：https://www.bilibili.com/video/BV1xF411h7zr  
- 字幕：AI（约 **2225** 字）；无时间戳纯文本

**要点**
1. 必须热身；伤根仍是量超承受 → 力量+控量，非马克操有无。
2. 动态操**非必须**；*mentally get in the zone*；多数熟人 10–20′ 慢跑够。
3. 本人：easy/long 仅慢跑 10–15′；质量课 + 少量动态 + **2–3×60–80 m strides**（几乎每次保留）。
4. 伤病角度先慢跑且慢跑够了；反对「跳舞激活才防伤」营销。
5. 年长/年限长或更需热身与拉伸；个人倾向慢跑后泡沫轴。

**选摘**
> 「你肯定是需要热身的，无论夏天冬天你都需要热身。」  
> 「受伤的根本原因是因为你的量太大……而不是你某一次跑步有没有做什么马克操。」

## 云健身（仰望尾迹云）

### BV1B14y1L7Cc · 明胶水解物和氨基葡萄糖
- URL：https://www.bilibili.com/video/BV1B14y1L7Cc  
- 字幕：AI（约 **1712** 字）｜教材：《健身营养全书》

**要点**
1. 标记明胶氨基酸进软骨 ≠ 特殊功效（鸡蛋同理）。
2. 研究多、硬证据少；老年关节炎≠年轻运动者；厂家「伪研究」打折。
3. 明胶：证据不足，一般不非常推荐；可当心情消费。
4. 氨糖：运动人群有用性不明确；指南类「不明确」推荐；鸡肋。
5. 尚无明确护关节补剂 → 靠安全合理训练。

**选摘**
> 「现在还没有明确的证据能说明明胶水解物对关节损伤有保护或者改善的作用。」

### BV1kM4y1r7HB · 酸碱平衡、蛋白质与骨骼健康
- URL：https://www.bilibili.com/video/BV1kM4y1r7HB  
- 字幕：AI（约 **5012** 字）

**要点**
1. 长期「酸性体质」对健康人基本不存在；有短暂波动与强调节。
2. 运动局部酸化→缓冲（呼吸等细胞外；肌肽细胞内）；β-丙氨酸证据偏耐力，力量者未必必要。
3. 高蛋白伤骨：**无明确证据**；缺钙人群风险叙事；**蛋白不足往往更伤骨**；保证钙即可。

**选摘**
> 「蛋白质摄入不足比蛋白质摄入过多对骨骼的危害更大。」

- URL：https://www.bilibili.com/video/BV1NC411t7NF

### BV146421c7Cc · 肌肉记忆 / 停训复训
- URL：https://www.bilibili.com/video/BV146421c7Cc  
- 字幕：AI（约 **3187** 字）

**要点**
1. 向心力量常可维约 4 周；离心/爆发掉更快。
2. 8–12 周力量损失常约 7–12%；多仍高于开训前。
3. 肌量掉可快于力量；快肌先掉（例 14 天 CSA −6.4%）。
4. 记忆：复训斜率陡，终点可追上不间断组 → 疑 OTS 可休息；肌核假说。
5. 复训早期蛋白 +0.3–0.5 g/kg、热量 +300–500 kcal/d 量级参考。

**选摘**
> 「如果说有过度训练的征兆，大胆的休息，停一段时间都没关系。」
