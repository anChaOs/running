## 山雨小月

### BV1pk4y167oM · 间歇原理（CORE）
- URL：https://www.bilibili.com/video/BV1pk4y167oM｜AI ≈ **6565** 字

**要点**
1. 间歇 = 课内刺激–恢复小循环；恢复与刺激同等重要；「间歇」指恢复间隔。  
2. interval ≠ intensity ≠ 无氧；可有 MP 到 1500 配速等不同强度。  
3. 变量：快跑时间、休息强度/时间、组数、组间间隔等。  
4. 心血管间歇：短偏送氧、长偏用氧；与 >90%VO₂max 累计时间相关；50–75% Tmax → 约 2.5–5 min 窗口叙事。

**选摘**
> 「间歇训练的本质呢实际上就是单次训练当中刺激恢复再刺激的有限小循环。」  
> 「interval不等于intensity，更不等于无氧的训练。」

### BV1XK411H74k · 间歇实践（CORE）
- URL：https://www.bilibili.com/video/BV1XK411H74k｜AI ≈ **4858** 字｜对照梨文 cv16277368

**要点**
1. 傻瓜式：5–8 min 快 / 休息一半 / 10k 或 ~90%HRmax / 累计 20–40 min 高强度。  
2. 纯新手先慢跑；新手 20 min 强度已很多；10k 配常≈LT。  
3. 马拉松间歇：LT～5k 常够，勿一味 VO₂max。  
4. 进阶：Thibault Model / MAP 曲线取点设计。

**选摘**
> 「每组的时长五到8分钟……休息时长是强度跑时长的一半。」  
> 「针对长距离，尤其是马拉松的训练的间歇，配速控制在Lt pace到5km比赛的配速就能够达到很可观的收益了。」

### BV1of4y1T71i · 周期安排（CORE）
- URL：https://www.bilibili.com/video/BV1of4y1T71i｜AI ≈ **2964** 字

**要点**
1. LSD 不必每周都拉长；隔周加长 + 中间周 75–90′ 中长。  
2. 短周末可 easy→目标 MP 渐进。  
3. 力量：周期早期多、末期少；周中多为慢跑。

**选摘**
> 「不用每周都跑这么长，你可以改成每隔两周往上加，中间一周呢你跑个中场距离，比如说75到90分钟就可以了。」

### BV1d7411g7tn · 10秒短上坡（CORE）
- URL：https://www.bilibili.com/video/BV1d7411g7tn｜AI ≈ **827** 字

**要点**
1. short uphill：组内 ≤30″（尤 8–15″），近最大努力；走下坡充分休。  
2. 好处：臀力量、触地经济性、部分代举铁、更专项。  
3. 勿加长组、勿压缩休息。

**选摘**
> 「短上坡跑，尤其是8~15秒这么短时间的上坡……我们这个训练要的就是中间充分的休息。」
