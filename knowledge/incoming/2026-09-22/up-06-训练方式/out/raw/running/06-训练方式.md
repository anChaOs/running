## 2. 轻松跑占比与周骨架（文字侧优先）

### 2.1 【UP 专栏】轻松跑操作 · cv4928724

- 作者：山雨小月 · https://www.bilibili.com/read/cv4928724  

**【UP 专栏可执行点】**

1. 高跑量 / 马拉松周期内：easy **≥70–75%** mileage；低跑量过渡期快跑比例可更高（个人例子）。  
2. easy 用**时间**衡量（约 ≥30 min 有意义；本人常 ≤90 min）；workout 用距离保证。  
3. 质量课之间至少 1 个 easy day；可选 progression：质量次日后由很慢加到 easy 偏快，effort ≤ comfortably hard。  
4. 配速锚：能聊天 / MAF / %HRmax / %5k pace（专栏给 50–75% 5k 等有氧区间叙事）。  
5. 经验立场：「破三前」可极少纯速度课，但需马拉松专项与 LT（**个人经验，非普适命令**）。

**【综合】** 与 Seiler LIT 主导同向；具体 % 是 UP 操作约定，非硬性生理常数。

### 2.2 【第三方梨】有氧五维 → 课型组合 · cv16277428（交叉有氧）

- mix workout + 分期；快肌/慢肌主导者质量课主体不同（tempo vs interval）——细节以 `02` 为准，本线只取「课型要写清目的」。

## 3. 间歇：原理 → 傻瓜模板 → Thibault/MAP

### 3.1 【UP 口播】间歇原理 · BV1pk4y167oM（CORE）

- URL：https://www.bilibili.com/video/BV1pk4y167oM  
- 字幕：AI，约 **6565** 字  

**【UP 口播要点】**

1. 训练本质 = 刺激→恢复→再刺激；间歇 = 单次课内的有限小循环；**恢复段与刺激同等重要**（「间歇」指恢复间隔，不是刺激段）。  
2. **interval ≠ intensity ≠ 无氧**；强度取决于要练什么（含 MP 间歇到 1500 配速间歇）。  
3. 可调变量：快跑时间、休息强度、休息时间、组数、组间间隔、每组长度等。  
4. 前几年先堆积跑量；平台期再找短板；正确间歇常是补短板工具。  
5. 生理分类口播（AI 常错听 lactate 等）：心血管送氧/用氧、乳酸耐受、乳酸再利用、乳酸阈、有氧耐力；亦可按 race pace 设计。  
6. 心血管间歇：越短越偏送氧、越长越偏肌肉用氧；效果与 **>90%VO₂max 区间累计时间**相关；常用 **50–75% Tmax**（Tmax≈4–9 min）→约 **2.5–5 min** 刺激窗口叙事。

### 3.2 【UP 口播 + 第三方梨】间歇实践 · BV1XK411H74k + cv16277368（CORE）

- 视频：https://www.bilibili.com/video/BV1XK411H74k（AI ≈ **4858** 字）  
- 梨文：https://www.bilibili.com/read/cv16277368（自称按 UP 讲述整理）

**【傻瓜式间歇｜UP 口播 / 梨文一致】**

| 参数 | 主张 |
|---|---|
| 单组快跑 | **5–8 min** |
| 休息 | 快跑时长的 **一半**（例 5′→ jog 2.5′） |
| 强度 | 从 **10k 赛配**起步；或 ~**90%HRmax**；保证下一组质量 |
| 累计高强度 | **20–40 min**（新手 20′ 已很多） |

**【UP/梨 强调】** 纯新手先慢跑积累；新手 10k 配常≈LT；马拉松间歇勿一味 VO₂max——**LT～5k** 常够用，太快徒增疲惫。

**【Thibault / MAP｜梨文详述 + 口播呼应】**

- MAP = Maximum Aerobic Power；曲线上取点 → 单组时长 × 次数 × %MAP。  
- 例 A：`4×(7×90s)@85%MAP`，组间 1′、大组间 3′（新手≈5k；高手≈10k–HMP）。  
- 例 C：`2×(5×90s)@100%MAP`，组间 3′、大组间 10′（偏短距离配速）。  
- 渐进：强度↑则时间↓；或同强度从多短组→少长组；避免总钉在同一强度。

**【综合】** 傻瓜模板 = **B 可试**（个体化）；Thibault = 设计下限工具，非唯一正确。

## 4. 马拉松课型：唠嗑大法 / 进阶答疑 / 周期 / 周记

### 4.1 【UP 口播】唠嗑式大法课例 · BV1zq4y197So（CORE）

- URL：https://www.bilibili.com/video/BV1zq4y197So｜AI ≈ **5085** 字  

**【当日课例（口播）】**  
热身约 5 km → **3 mile（≈5 km）@ MP～HMP（tempo）** → 休息约 10′ 慢跑 → **6×1 km**（计划约 HMP→10k，中间 **400 m jog**）→ 冷身。口播实测 tempo ≈ 3:43/km 量级；1k 组约 3:33–3:36 一带（个人当日数据，非处方）。

**【方法立场】** 间歇目标配速看**周期阶段**；周期早期可更偏心肺速度，专项阶段围绕 MP/HMP；马克操/技术 ≠ 每次必须（一周一两次量级叙事，交叉伤病热身）。

### 4.2 【UP 口播】进阶唠嗑 · BV1VU4y1c7VL（CORE）

- URL：https://www.bilibili.com/video/BV1VU4y1c7VL｜AI ≈ **5692** 字  

**【答疑摘取】**

- **长距离时长：** 口播倾向控制在约 **2–2.5 h** 量级（慢者距离自然更短）；过长对有氧收益打折、更偏意志训练叙事。  
- **心率：** 自认不靠心率管强度；初学/减脂可用低心率；质量课更在意**目标配速下的经济性**（热天达不到配速≠简单改用心率为同等刺激）。**此为 UP 个人立场，非否定心率工具。**

### 4.3 【UP 口播】周期安排答问 · BV1of4y1T71i（CORE）

- URL：https://www.bilibili.com/video/BV1of4y1T71i｜AI ≈ **2964** 字  

**【方向性建议（针对跑友计划，非通用处方）】**

- 周末 LSD：**不必每周都拉长**；可隔周加长，中间周中长 **75–90′**。  
- 样例节奏：21k → 15k → 24k → 16k → 27k → 15–16k…（示意）。  
- 短周末可做 **easy→目标 MP 渐进**。  
- 周期早期多力量防伤；末期专项上来后可减力量。  
- 周中其余多为慢跑；长周末那一周周中相应减载。

## 5. 上坡 / strides / 热身接口 / 夏训 / 长期地基 / 800 sharpening

### 5.1 【UP 口播】10 秒短上坡 · BV1d7411g7tn（CORE）

- URL：https://www.bilibili.com/video/BV1d7411g7tn｜AI ≈ **827** 字（短片）  

**【处方轮廓】** 组内 **≤30″**（尤其 **8–15″**），接近最大努力；组间**走下坡充分休息**（恢复 ≫ 刺激）。目的：臀力量、触地经济性、部分替代举铁、**更 running-specific** 的神经肌肉刺激。  
**【禁忌操作】** 勿故意加长组、勿压缩休息——否则动作变形，目的落空。可加在 easy 末（desc 亦同）。

### 5.2 【UP 口播】上坡要旨 · BV1yM411U7XV（可选收录）

- URL：https://www.bilibili.com/video/BV1yM411U7XV｜字幕 **zh-CN**（非 ai-zh 标签）≈ **2813** 字  

| 类型 | 时长 | 目的（口播） | 组数量级 |
|---|---|---|---|
| 神经肌肉短坡 | ~8–15″ | 神经控制 / 形式 | **6–10 组**足够；勿 20+ |
| 送氧短中坡 | **30–90″** | 运氧 | 10k–5k（可至 3k）effort |
| 用氧长坡 | ~**3′** | 用氧（似平路 800 间歇） | 例：5×3′ @5k effort，jog 下坡 |

上坡可一定程度代力量；无坡→跑步机连续上坡或爬楼。

### 5.3 【UP 口播】热身 / strides · BV1xF411h7zr（交叉伤病）

- 必须先慢跑热身；质量课保留 **2–3×(60–80 m) strides**；马克操非必须。详见 `05`。

### 5.4 【UP 口播】夏训 · BV1dg411Z7YT（交叉有氧）

- 业余夏训原则叙事：恢复变慢 → **保跑量刺激**时常需**降强度或拆分**质量/长距离；质量课该打的配速仍尽量打到，可用分段；恢复不过来就果断减量。细节见 `02`。

### 5.5 【UP 口播】长期主义地基 · BV19bXqYAEeo（CORE）

- URL：https://www.bilibili.com/video/BV19bXqYAEeo｜AI ≈ **5444** 字  
- **Lydiard** 遗产叙事：有氧基础→再叠强度；高里程有氧仍是优秀马拉松核心；周期化：有氧+力量 → 无氧 → sharpening。  
- Base 周示意（口播量级）：多日 30–90′ easy，可插坡；长距离以 ~90′ 为锚上下浮动——**示意非照抄课表**。

### 5.6 【UP 口播】800 间歇 sharpening · BV1jL4y1z7LZ（可选）

- 赛前磨刀：例 **10×800**，休息叙事含 400 jog；配速可 10k→5k 渐进。口播对比 **Yasso 800**（组数周周加、用 800 成绩粗映射马拉松目标——**粗工具，非精确预测**）。

## 6. 云健身 · 力量方法（训练方式 CORE 4）

> 服务跑者的接口：动作意图、性别风险提示、平台期负荷与热量——**非跑姿课表**。

### 6.1 【云健身】增肌动作速度 · BV1Wd4y1X7YC

- URL：https://www.bilibili.com/video/BV1Wd4y1X7YC｜AI ≈ **2883** 字  
- **速度–张力关系：** 向心越快张力越小（重负荷自然变慢）；离心相反。  
- **误解：** 刻意慢慢推 ≠ 自动更大张力；重负荷下主观仍应尽力快推，客观上变慢。  
- 爆发力曲线 ≠ 肌肉力量曲线；学术界对「快/慢更好」无最终一刀切结论，目的不同答案不同。

## 9. 【综合】可执行笔记要点（非 UP 原话处方）

**业余周骨架示例：**

- 3–5 次 easy（真能聊天、时间达标；高跑量期 mileage 大部分 easy）  
- 1 次质量：LT 长间歇/节奏，或傻瓜式 5–8 min 组，或 MP/HMP 专项组合  
- 1 次长距离（多数时间仍有氧；时长量级参考 UP 答疑，按能力缩放）  
- 可选：easy 末 **strides / 8–15″ 短上坡**；每周 1–2 次跑者力量（蹲、单腿、小腿、髋；女跑者注意后侧平衡）

**质量课书写字段：** 目的｜强度锚｜单组｜休息｜累计高强度｜前后 easy。

**周期：** 基础有氧（Lydiard 味道）→ 阈值/专项 → sharpening（如 800）→ 减量；夏训降强度或拆分；力量前多后少。
