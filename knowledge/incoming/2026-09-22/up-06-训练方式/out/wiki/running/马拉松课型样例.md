# 马拉松课型样例

## 结论

以下为【UP口播】课例/周记结构，**个人数据非处方**。

| 来源 | 模板 |
|------|------|
| BV1zq 唠嗑课例 | ~5k 热身 → **3 mile @MP–HMP** → 休 → **6×1k**（HMP→10k）+400 jog → 冷身 |
| BV1of 周期 | LSD **隔周加长**；中间周 75–90′；短周末可渐进到 MP；力量前多后少 |
| BV147 周记样例 | easy+短坡 / 1′上坡 / 中距离 / 恢复 / MP 渐进 / 恢复 / 变速+MP（个人 sub240 周，约 55 mile） |
| BV1VU 长距离 | 口播倾向 ~**2–2.5 h** 卡时长；过长更偏意志 |

方法立场：间歇目标配速看**周期阶段**；consistency > 单组洁癖；心率立场=UP 个人（质量课更在意目标配速经济性），**非否定心率工具**。

## 概念

- BV147 自我说明：相对全马高峰跑量约减四成，换短距离速度；强度日更密但单次累计强度距离更短。
- BV1Eh 错轨字幕 → **不采用**（定稿已 SKIP）。

## 对训练的启发

- 抄结构不抄配速；长距离勿无限拉长「为了意志」。
- 勿把 UP 个人周记当自己的处方。

## 待验证

- 各课例当日实测配速仅个人记录。
