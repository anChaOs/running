# 周结构真easy与质量间隔

## 结论

【UP专栏】cv4928724：高跑量/马拉松周期 easy **≥70–75%** mileage；easy 用**时间**衡量（约 ≥30′ 有意义；本人常 ≤90′）；workout 用距离保证；质量课之间至少 **1 个 easy day**。配速锚：能聊天 / MAF / %HRmax / %5k。【综合】周计划 = **大量真 easy** + **少而写清的质量课** + **可恢复的长距离** +（可选）短上坡/strides/力量。与 Seiler LIT 主导同向；具体 % 是 UP 操作约定，非硬性生理常数。**笔记≠教练处方。**

## 概念

- 可选 progression：质量次日后由很慢加到 easy 偏快，effort ≤ comfortably hard。
- 【第三方梨】课型要写清目的（交叉有氧五维提纲，勿冒充口播总表）。

## 对训练的启发

- 自检：easy 是否伪装成节奏？质量之间是否有真恢复日？
- 低跑量过渡期快跑比例可更高（专栏个人例子）——勿机械套 75%。

## 待验证

- 「破三前极少纯速度课」为个人经验立场，非普适命令。
