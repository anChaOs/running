# 傻瓜间歇模板

## 结论

【UP口播】BV1XK +【第三方】梨文 cv16277368（一致）：单组快跑 **5–8 min**；休息=快跑的 **1/2** jog；强度从 **10k** 起或 ~90%HRmax；累计高强度 **20–40 min**（新手先 20′）。马拉松：间歇锚在 **LT～5k**，勿一味 VO₂max。【进阶】Thibault/MAP 曲线取点（例 `4×(7×90s)@85%MAP`）——设计工具非唯一正确。【原理 BV1pk】恢复段与刺激同等重要；效果与 >90%VO₂max 累计时间相关。

## 概念

| 参数 | 主张 |
|------|------|
| 单组 | 5–8 min |
| 休息 | 半时 jog |
| 强度 | 10k 起 / ~90%HRmax |
| 累计 | 20–40 min |

纯新手先慢跑积累；新手 10k 配常≈LT（口播/梨）。

## 对训练的启发

- 质量课写清：目的/锚/休息/累计高强度。
- 太快徒增疲惫时先降锚回 LT～5k。

## 待验证

- Thibault 例题为示意；个体 MAP 测定不在本笔记。
