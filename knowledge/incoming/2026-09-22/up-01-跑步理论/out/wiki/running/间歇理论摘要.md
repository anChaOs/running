# 间歇理论摘要

## 结论

本主题只保留**理论摘要**；完整五类间歇与傻瓜模板参数见有氧主题包。【UP口播】BV1pk：间歇得名于**恢复段**；按目的分心肺 / 耐酸 / lactate reuse（**必须 jog**）/ clearance / aerobic resistance；心肺效果∝待在 ≥90% VO₂max 区时间；实用 3–5′ 或 30–60″ 短间歇；累计高强度约 **15–30′**；非短板可 2–3 周一次。【UP口播】BV1XK：傻瓜式 5–8′ / 休≈半时 / 10k 起或 ~90%HRmax / 累计 20–40′；马向 **LT～5k** 已够，不必一味 VO₂max。

**【第三方】梨文** cv16277368/77428：五维课型排序作**提纲**；与 BV1pk「间歇分类」**结构不同**，勿把梨文表直接标成 UP 口播。

## 概念

| 来源 | 理论要点 |
|------|----------|
| BV1pk | 五类生理目的；reuse 必须 jog；心肺累计 15–30′ |
| BV1XK | 傻瓜参数；Thibault/MAP 选点；马向 LT～5k |
| BV1VU | 短/长间歇皆可，心肺课看总高强度时间 |
| 梨文 | 【第三方】提纲，≠ UP 口播总表 |

**【综合】** 间歇是「对准短板的质量工具」，不是「越快越好」；与轻松跑大比例是同一 TID 硬币两面。

## 对训练的启发

- 质量课写清目的（心肺 vs reuse vs MP）；consistency > 单组±5″（BV1zq）。
- 需要可执行模板时打开有氧包「傻瓜间歇」页，勿在本页发明参数。

## 待验证
