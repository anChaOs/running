## 2. 【山雨小月·专栏】步态 / 热身观（文字侧优先）

### 2.1 步频 · cv6092643（关联 BV12E411w7zT · **无可用 AI字幕**）

- URL：https://www.bilibili.com/read/cv6092643  
- 关联视频：https://www.bilibili.com/video/BV12E411w7zT（transcript **0 bytes**，历史上无可用 AI字幕 → **以本专栏为准，不编造口播**）

**【山雨小月·专栏要点】**

1. 拆穿「180 步频激活弹性、省氧 20%」二手传播；追溯 Pose Method 站点后核对 *J Appl Physiol* 1964：原文步频约 **150–250/min** 即可高效利用弹性势能，**无「180」**。  
2. 「不存在单一最优步频」；业余研究平均约 155.6、耗氧最优约近 170 ≠ 人人 180。  
3. **不要刻意改步频/步幅**（无明显 overstride）；用 strides（多组 10–20 s 短冲）经 neuromuscular 提升经济性，结果可能是步频或步幅变化。

### 2.2 本人步频实例 · cv6340376

**【山雨小月·专栏】** 2016 随心跑约 169 spm（~6:08/km）；系统训练后曾 180+、200+，2019 轻松跑约 185——**步频是能力变化的表征，不是主动练的目标**。

### 2.3 马克操 · cv8118914

**【山雨小月·专栏】** Mach drills 原为冬季模拟冲刺激活，**非为防伤/改长跑跑姿设计**；可作慢跑后的可选热身，**绝非必须**；「防伤激活」缺少根据。长跑经济性更靠 goal pace + plyometrics / strides，而非把 sprint form 当长跑保险。

### 2.4 轻松跑中的功能观 · cv4928724（交叉伤病叙事，本线只取功能句）

**【山雨小月·专栏】** 伤病常见叙事含相关肌力不足；慢跑可掩盖弱点；底线 form：挺胸抬头、核心稳定；大体重可先非冲击+膝周臀核心再跑。——机制细节与诊疗边界见 `05`。

### 2.5 方法论 · cv6381717

**【山雨小月·专栏】** 怀疑「必须/一定」；短期小样本易被过度推广；慢跑+肌力维持 muscle mass 的组合思考。

## 3. 【山雨小月·口播】跑姿 / 经济性 / 姿势跑法

### 3.1 BV1N5411r7GH · 跑姿与经济性/伤病（CORE）

- URL：https://www.bilibili.com/video/BV1N5411r7GH｜AI ≈ **14409** 字｜理论来源口播：坤帅文 + 本人理解

**【山雨小月·口播要点】**

1. 业余常把跑姿与成绩强挂钩；口播结合专业文章拆解。  
2. **同速下步频高低对成绩影响可忽略量级叙事**；一般人步频范围高低相差约几十；从自然步频切到非自然步频 → 经济性下降。  
3. 每人有自己的最优步频范围（口播：最优 ±2–3 量级叙事）；**不是人人 180**。  
4. 「不正确跑姿」本质常是 **髋/大腿力量偏弱**；力量上来后姿态常自然改善（与伤病线同向）。  
5. **姿势跑法**在口播中明确标为**商业名词**；勿当作提高经济性的唯一正解。  
6. 躯干/腿部力量不足时，苦练「姿势口令」收益常不如补力量。  
7. 可执行方向：排除明显 overstride；专项力量 + neuromuscular 手段（strides/短上坡等），让神经系统优化步频或步幅。

**【综合】** 与专栏「勿迷信 180、勿盲目改步频」一致；与 Barton 步态再训练文献：力学可改、伤者高质量 RCT 有限 → **nuance**（见 §7）。

### 3.2 BV1eF411e7Rn · 姿势跑法随心聊（CORE）

- URL：https://www.bilibili.com/video/BV1eF411e7Rn｜AI ≈ **5380** 字

**【山雨小月·口播要点】**

1. 再次强调姿势跑法是**商业概念**；口播称有使运动员经济性恶化的案例叙事。  
2. 高经济性跑姿是训练与能力的结果，不是买一套口令就能装上。  
3. 想更经济 → 训练与力量；想更不经济 → 硬套非自然模式（口播反讽结构）。

## 4. 【山雨小月·口播】热身 / 拉伸 / 短上坡神经刺激

### 4.1 BV1xF411h7zr · 跑前热身（CORE）

- URL：https://www.bilibili.com/video/BV1xF411h7zr｜AI ≈ **6001** 字

**【山雨小月·口播要点】**

1. **必须热身**（冬夏皆然）；时间个体化。  
2. 受伤根本原因是**量（强度×跑量）超过承受**，靠力量与控量，**不是某次有没有做马克操**。  
3. 动态操 / skip 等 **非必须**；教练原话叙事：*do whatever you need to mentally get in the zone*。  
4. 本人习惯：easy/long → 仅慢跑约 10–15′；质量课 → 慢跑 + 少量动态 + **2–3×60–80 m strides**（几乎每次保留）。  
5. 与专栏马克操立场一致：可选，非防伤保险。

### 4.2 BV1o7411F77p · 跑后拉伸（CORE）

- URL：https://www.bilibili.com/video/BV1o7411F77p｜AI ≈ **4408** 字

**【山雨小月·口播要点】**

1. **科学无定论**；只分享个人习惯（Garmin 营 + 他人经验），九动作顺序固定。  
2. 动作链：小腿 → 大腿前侧 → ITB/外侧 → 大腿后侧 → 臀+后侧 → 内收 → 坐姿脚掌相对 → 抱膝压臀 → 髂腰肌（口播演示细节以原片为准）。  
3. **不承诺防伤**；当舒适度/习惯即可。

### 4.3 BV1d7411g7tn · 10 秒短上坡（CORE）

- URL：https://www.bilibili.com/video/BV1d7411g7tn｜AI ≈ **1923** 字

**【山雨小月·口播要点】**

1. **short uphill**：组内常控在 **30″ 内**（尤 **8–15″**），近最大努力；**走下坡充分休息**（恢复远长于刺激）。  
2. 目的：**neuromuscular / running economy / form**——臀力量、触地经济性、部分替代 gym 力量且更 running-specific。  
3. **勿延长组、勿压缩休息**，否则下一组 form 崩，目的落空。  
4. 与 30–90″（偏送氧）、>90″（偏用氧）上坡目的不同（口播分类）。

### 4.4 BV1yM411U7XV · 上坡要旨（CORE / 与 `06` 交叉）

- URL：https://www.bilibili.com/video/BV1yM411U7XV｜字幕约 **7479** 字（既有轨）

**【山雨小月·口播要点】**

1. 当日课例叙事：easy 热身 + 多组约 3′ 上坡 @5k effort + jog 下坡 + 冷身（个人课表，非处方）。

3. 更长上坡转向送氧/用氧能力——课型细节主见 `06`；本线保留「短=神经」接口。

## 5. 【云健身 · 仰望尾迹云】能量消耗 / BMR / 吸收率（CORE 4 · 本轮新抽）

> 四片同属「云氏运动生理学」热量模块；AI 字幕已入库。数字与公式名为**口播量级/转述**，实践中作估算框架，非实验室金标准。

### 5.1 BV1Sd4y167Tm · 每日热量总消耗计算（CORE）

- URL：https://www.bilibili.com/video/BV1Sd4y167Tm｜AI ≈ **2744** 字（新建目录）

**【云健身·口播要点】**

1. 日总消耗 ≈ **基础代谢 + 食物热效应（TEF）+ 活动热消耗**（有的体系把生热作用单列第四部分；减脂增肌不必过细）。  
2. **TEF**：与进食量正相关；蛋白 TEF 最高（口播约 20–30% 摄取能量），碳水次之（约 5–10%），脂肪最低（约 0–5%）；机制叙事：氨基酸→脂肪路径耗能高于糖原合成、高于脂肪储存。  
3. 真实世界混合膳食下 TEF 差别有限 → **减肥仍主要看总热量**，一般不必纠结 TEF。  
4. 实用估算法一：**BMR × 活动系数**（双标水经验表；久坐办公约 1.4–1.5；有运动可再加约 0.3 量级叙事）。  
5. 实用估算法二：含年龄/身高/体重/活动系数（口播称 PAC）的公式；例：35 岁女、70 kg、1.68 m、活跃 → 约 **2493 kcal/d**（口播例算）。  
6. 立场：估算够用；勿用狙击枪精度要求火箭炮；做多了可凭经验模糊处理。

### 5.2 BV1n14y1v7dD · 基础代谢误解与实用知识（CORE）

- URL：https://www.bilibili.com/video/BV1n14y1v7dD｜AI ≈ **2481** 字（新建目录）

**【云健身·口播要点】**

1. 日消耗三部分：基础代谢、食物热效应、活动热效应；本片聚焦 BMR。  
2. **BMR ≠ 全天总消耗**；翻身、玩手机、通勤都不算 BMR。  
3. BMR vs RMR：严格有别，实践常混用。  
4. BMR（量）vs BMR 率（速率，如 kcal·kg⁻¹·h⁻¹）。  
5. 实验室测量条件很严（禁剧烈运动、空腹、舒适安静、测耗氧等）。  
6. **健身房/体脂秤「基础代谢」极不准**：多为生物电阻抗估体成分后再套公式，不是真测 BMR；可参考但勿迷信。  
7. 推荐 **毛德倩公式**（中国人数据；仅需体重）：男 `(48.5×体重 + 2954.7)/4.184` 千卡；女 `(41.9×体重 + 2869.1)/4.184`（口播写法；以教材/原文为准）。  
8. 肌肉是耗能大户但非唯一；脑与内脏占比也不小 → 「只靠测肌量估 BMR 最准」是想当然。

### 5.3 BV13W4y1e7Kp · 多吃不胖的热量特点（CORE）

- URL：https://www.bilibili.com/video/BV13W4y1e7Kp｜AI ≈ **2796** 字（新建目录）

**【云健身·口播要点】**

1. 健康人吸收率都很高 → 「多吃不胖=吸收差」通常错（详见 5.4）。  
2. 多吃不胖 ≈ **消耗高于想象** 和/或 **摄入低于想象**（常两者兼有）。  
3. 消耗侧隐形因素叠加：  
   - **BMR** 个体变异（口播：均值 ±约 21% 量级叙事）；  
   - **NEAT**（非运动产热：走路、家务、姿态张力、坐不住 vs 瘫沙发）；  
   - **产热**（棕色脂肪、肌肉产热活动强弱）；  
   - **无效循环**（口播戏称「细胞抖腿」：离子泵来回、底物无效往返等）。  
4. 摄入侧：同事「吃得一样」常是错觉；油腻偏好、份量、零食、应酬可日差数百 kcal。  
5. 「少吃不瘦」口播指向：往往并不是真的吃得少（另片展开）。  
6. 方法论：反对单因素归因；胖瘦仍跟热量有关。

### 5.4 BV1ae4y1b7Xf · 减肥与消化吸收率（CORE）

- URL：https://www.bilibili.com/video/BV1ae4y1b7Xf｜AI ≈ **1977** 字（新建目录）

**【云健身·口播要点】**

1. 营养素确实不能 100% 吸收；混合膳食吸收率口播按碳水 **98%**、脂肪 **95%**、蛋白 **92%** 量级。  
2. 健康人吸收率已经很高；无持续明显消化道症状就不必担心「吸收特别差」。  
3. 「一吃就胖=吸收太好」也不成立：吸收上限空间很小。  
4. **Atwater 4-4-9 已计入典型消化吸收与可代谢能** → 日常算热量**不必再扣一层吸收率**。  
5. 个体差别存在但很小，减脂/增肌场景可忽略；水果碳水、植物蛋白吸收率略低，混合膳食一平均仍回到 4-4-9 框架。

## 9. 【可执行笔记要点】

1. **步态：** 先排除明显 overstride/疼痛动作；不要为「180」强改；用 strides / 短上坡让神经肌肉自己优化。  
2. **每周功能刺激：** easy 末可加 **若干组 8–15″ 上坡或平地 strides**（次最大～近最大，**充分恢复**）。  
3. **热身：** 默认慢跑；质量课保留 strides；马克操可选非必须。  
4. **拉伸：** 当舒适度习惯，**不承诺防伤**。  
5. **力量：** 蹲、单腿、小腿、髋——对齐 RE/成绩文献，而非追求 VO₂max。
