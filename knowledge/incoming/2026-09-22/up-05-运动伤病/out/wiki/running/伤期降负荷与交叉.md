# 伤期降负荷与交叉

## 结论

【综合】+【UP】行动树：越跑越痛 / 骨痛夜痛 / 锁定肿胀 / 神经症状？→ **是**则停冲击、临床评估（勿 run through）；**否**（疑劳损）→ 降量或降强度 + 力量 → 交叉保有氧（车/游/椭圆/水跑/开坡）→ 能跑则常「**保强度减量**」（交叉【口播】BV1384）。【UP BV18】个人 *run through* 叙事 ≠ 通用医嘱。【口播】BV12V：跑的离心冲击使恢复慢 → 非冲击交叉减轻负担。

## 概念

- 伤期目标：保住有氧底座与神经肌肉，同时把组织尖峰负荷降到可适应范围。
- plyometrics 可在合适阶段保 power（停训交叉句）。

## 对训练的启发

- 先分清红线 vs 劳损路径；红线不硬扛。
- 交叉不是偷懒，是负荷管理。

## 待验证

- 具体伤种能否继续跑必须个体临床判断。
