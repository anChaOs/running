# 常见跑步伤与力量把手

## 结论

【UP口播】BV17 训练笔记式整理，**非诊断**；同名疼痛可能对应不同组织；口播自陈须结合自身。优先把手常是相关力量，而非商业改姿。

| 伤（口播叙事） | 优先想 | 跑姿/鞋备注 |
|----------------|--------|-------------|
| 跟腱 | 小腿力量；离心提踵/heel drops（中段 vs 止点不同）；≥数月量级 | 前掌更累跟腱；可试高落差 |
| 髌腱 | 大腿前后柔韧；离心（斜面蹲等） | 后掌或增风险→中/前掌或低落差 |
| ITBS | **髋外展**力量；非盲目「揉束」 | 臀下摆是弱的表现；上坡常减痛【BV18交叉】 |
| 足底筋膜 | 减冲击/体重管理；伤期可提步频 | 慎极简/裸足 |
| 腘绳 | 补**臀**（含对侧） | 少怪「姿势」 |
| 小腿/胫区 | 小腿力量；落地方式 | 前掌→中后掌或减负 |
| 跑步膝 | 髋+大腿力量 | 改姿不如补力 |
| 骨应力 | 钙/能量/月经；减冲击；小腿 | 提步频；缓冲/trail；**须临床** |

## 概念

- 肌腱命名「-itis」多为历史遗留；实质常纤维级物理损伤（口播）。
- ITBS 机制更新：较信服「压迫邻近脂肪垫」叙事，纯摩擦说遭质疑（口播）。

## 对训练的启发

- 按部位选力量，而不是先买姿势课。
- 骨应力疑似 → 临床红线，不在本页「练着看」。

## 待验证

- 各伤种离心协议细节以原片/临床为准；例 3×15×≥3 月为口播叙事量级非处方。
