## 2. 负荷–能力模型（总框架）

### 2.1 【UP 口播】总命题 · BV17i4y187vb（CORE）

- URL：https://www.bilibili.com/video/BV17i4y187vb  
- 字幕：AI，近完整（文件约 **15336** 字）｜理论来源口播声明：**坤帅**文 + 本人理解  
- 接跑姿经济性篇（BV1N）；本片「跑步部分反而很少」——主讲伤病种类、触发、与跑姿关系。

**【UP 口播要点】**

1. **无人保证不受伤**；外部触发可能有几十种；遇伤找靠谱医生比网上搜答案有意义。  
2. **几乎所有伤病最终可归结到：过度训练 + 相关肌肉力量不足。**  
3. 跑步是耐力运动：练少挖不出潜力，练多易伤——**找到适合自己的量并可持续提高**，才是「内功」；间歇/乳酸/节奏是「招式」。  
4. 跑姿（如落地方式）的确造成不同力学影响，但**A→B 纠正往往带来新问题**；许多「坏跑姿」本质是肌力/激活问题，力量上来后姿态常自然改善（与 BV1N 同向）。  
5. 按组织分三大类：**肌腱韧带伤 · 肌肉伤 · 骨伤**。

**【综合】** 与专栏「加量太快/单次太快」叙事、文献负荷管理共识同向；模型语言 = **施加负荷 vs 组织能力**。

### 2.2 【UP 专栏】轻松跑文中的伤病叙事 · cv4928724

**【UP 专栏】** 伤病「大概率」与跑量加太快或单次太快有关，但不绝对；**不认为跑姿与伤病有太大关系**（除非严重内外翻/极度怪异）；机制叙事：相关肌力不足（例臀弱→ITBS）；慢跑可掩盖弱点，一上来快跑更快暴露；FIRST 式「一周三次都快跑」认识者中不少最终受伤，不受伤者常有力量或交叉支撑。

### 2.3 跑姿 / 步频 · 交叉引用（不整段复制）

| 来源 | 伤病相关结论 | 详见 |
|---|---|---|
| BV1N5411r7GH【口播】 | 不正确跑姿本质常是髋/大腿弱；勿 overstride；补力量后姿态或自然变 | `01` §5 |
| 专栏 cv609/634 + BV12E **无字幕** | 勿为防伤盲目追 180；无显著 overstride 则交神经优化；伤期为减冲击可**临时**提步频（BV17 足底/骨伤段） | `01` §4 |
| Barton et al. 2016【文献】 | 步态再训练可改即时力学；伤者高质量 RCT 仍有限 | §7 |
| BV1384【口播·交叉有氧】 | 伤病能跑则**保强度减量**；交叉保有氧；plyometrics 保 power | `02` §6 |
| BV12VkoYUEfT【口播】 | 跑的离心+冲击（约 2–3×体重）→恢复慢；车等非冲击交叉利于恢复负担 | `02` 摘录 |

**【综合 nuance】** 「别迷信改跑姿治百病」**同意**；「力学完全无关」过强——先**负荷管理 + 力量**，再个体化 gait cue；拒绝商业姿势套路。

### 2.4 模型一页图【综合】

```
外部负荷（量×强度×坡度×路面×鞋×体重×站立职业…）
        ↓ 超过 ↓
组织能力（肌腱刚度/肌力/骨密度/修复速度/既往伤…）
        ↓
症状 / 代偿 / 新「坏跑姿」表象
        ↑
把手：减负荷尖峰 · 渐进暴露 · 针对性力量 · （必要时）临时改落地/步频/鞋 · 交叉保心肺
```

## 3. 常见伤病与预防（【UP 口播】BV17）

> 以下为训练笔记式整理，**非诊断**。同名疼痛可能对应不同组织问题；口播自陈「对症下药仍须结合自身」。

### 3.1 肌腱 / 韧带类

#### （1）跟腱病（口播仍称「跟腱炎」；强调多非经典炎症）

| 项 | 【UP 口播】 |
|---|---|
| 分型 | **中段 midportion**（后跟偏上，多数）；**止点型 insertional**（后跟偏下，少数） |
| 命名 | 「-itis」多为历史遗留；实质常是纤维级物理损伤 |
| 功能 | 落地与蹬地储能–释能；刚度高、储能强 → 超能力时易伤 |
| 跑姿相关 | 有限证据倾向：**前掌着地更易累及跟腱**；外翻等无定论 |
| 其他 | 跑山每步负担大，但口播称亦有研究显示影响未必如想象大 |
| 预防/处理叙事 | **小腿力量**关键；中段：直腿/屈膝台阶提踵类；止点：**flat eccentric heel drops**；例：1×/日、3×15，**≥3 个月**才谈质变；可考虑高落差缓冲鞋助过渡后掌 |

#### （2）髌腱病（「髌腱炎」）

| 项 | 【UP 口播】 |
|---|---|
| 实质 | 同样多非炎症；解剖上更接近连接两骨的韧带，材料类肌腱 |
| 跑步中 | 破坏性常不如篮排；球类背景者跑步较少新发，除非大量跑山 |
| 相关因素 | 脑补很多（腿长差、外翻等）；口播称相关度较高的是**大腿前后柔韧性** |
| 跑姿 | **后掌**或增加风险；已有症状且典型后掌 → 可尝试过渡中/前掌或低落差鞋 |
| 离心 | 斜面深蹲等离心变式作恢复叙事 |

#### （3）髂胫束综合征 ITBS

| 项 | 【UP 口播】 |
|---|---|
| 结构 | 髋→胫骨上方长结缔组织；助落地时膝/髋控制 |
| 机制更新 | 「摩擦综合征」遭质疑（结构上难直接摩擦；且久坐加重不符纯摩擦）；较信服说法：**压迫邻近富含血管神经的脂肪垫** |
| 痛点 | 屈膝约 **20–30°** 时最明显 → 下坡/下楼剧痛 |
| 相关度最高 | **髋外展肌力量**不足 → 髋内收 → ITB 过度受压；臀下摆常是表现而非「要改的姿势」 |
| 预防 | 加强髋外展；**力量上来跑姿问题常自消**，不必主动改姿 |

#### （4）足底筋膜病

| 项 | 【UP 口播】 |
|---|---|
| 实质 | 非肌肉肌腱，但是结缔/纤维损伤；非跑者独有（久站/久走） |
| 危险时相 | 落地承重；**蹬地腾空**（跟离地、前掌发力、筋膜拉长）伤害往往更大 |
| 晨起剧痛 | 夜间修复收缩 → 下床第一步二次破坏叙事 |
| 因素 | 体重↑、站立/走/跑过久、年龄↑（愈合慢）、触地冲击大；**足弓高低证据不明显**（打网文脸） |
| 预防叙事 | 健康减重（过度节食反而伤骨）；伤期可**提步频减冲击**（先养伤，不论经济性）；前掌/极简鞋/裸足常把负荷转到足踝小腿 → 对筋膜弱者不利；中/后掌或更稳妥 |

### 3.2 肌肉类

| 伤 | 【UP 口播】要点 |
|---|---|
| **腘绳拉伤** | 臀弱/激活不足时腘绳代偿送髋；亦可因**对侧**臀弱导致本侧代偿——右腿伤勿断定只在右侧 |
| **小腿拉伤** | 着地+蹬地用力；前掌→中/后掌或减负；否则靠增强肌–腱能力 |
| **胫骨区部分** | 分析类似小腿；增小腿力量；极端可涉轻微骨伤（见下） |

### 3.3 骨 / 关节软骨相关

| 伤 | 【UP 口播】要点 |
|---|---|
| **跑步膝（髌股区）** | 主流叙事：滑动轨迹问题致表面/邻近痛感；**无证据说软骨必已损**；本质常髋/大腿弱 → 落地冲击与异常滑动；女生髋力常较弱 → 更易；大腿前+小腿后柔韧性差或需膝代偿；拉伸/瑜伽**可能**有助；纠正跑姿不如补力量 |
| **半月板** | 口播认为跑步中几乎可忽略；中文材料常过度关联；马前后 MRI 类研究口播称未见不良影响；若仍担心：少大下坡冲击、提步频、加强关节周肌力；高冲击项目（篮羽跳）风险叙事更高 |
| **应力性骨折 / 胫骨炎极端骨性部分** | 长期超负荷微裂；适度冲击可增强骨，持续超过自愈则骨折；骨强者不易：童年负重/球类冲击、曾较重后运动减重者相对优势、小腿肌发达；女生骨密度较低，月经紊乱→更低；预防：补钙勿过度节食（钙/铁/维C）、提步频、后掌→前掌可减胫骨冲击（负荷转移到足）、增小腿肌腱、高缓冲鞋、trail/草地（软+凹凸分散冲击） |

### 3.4 【UP 口播】收束

理解跑步模型 → 按训练史/伤史找弱项增强肌腱 → 在模型信息上选环境与强度；业余遇伤优先**靠谱理疗/医生 + 力量诊断**，而非只搜网文。

## 4. 热身 / 拉伸 / 马克操立场

### 4.1 跑前热身【UP 口播】BV1xF411h7zr（约 2225 字）

**【UP 口播要点】**

1. **夏冬都需要热身**；具体时长因人、因日而异；「怎么跑都进不了状态」是常态（疲劳积累）。  
2. 受伤根本仍是**量（强度+跑量）> 承受** → 力量 + 控量，**不是**某次有没有做马克操。  
3. 动态热身（skip A/B、高抬腿、后踢等）：**非必须**；名教练原话大意：*do whatever you need to mentally get in the zone*。国外熟人多数 **10–20′ 慢跑**即够。  
4. **本人习惯（方向性参考，非对错标准）：**  
   - Easy / long：慢跑开始 **10–15′**，无额外花样；  
   - 质量课：慢跑热身 → 可做少量高抬腿/后踢/skip → **更重要：2–3× 60–80 m strides**（strides 几乎每次保留）；筋膜枪可选；整段动态约 5–10′，非每次全做。  
5. 伤病角度：**一定先慢跑**；慢跑够不够？口播结论**够了**；反对「必须跳舞式激活才防伤」话术。  
6. 生理：高低功率输出时肌肉募集与血液化学不同；慢跑→快跑需渐进，间歇上来勿过猛。  
7. 短距离赛热身可很长（含动态维持状态）；职业者肌肉刚度利成绩但伤病角度不利 → 或需更多拉伸/滚轴；**年长/年限长**者拉伸与热身或更重要——仍≠必须跳舞动作；口播个人倾向慢跑后滚泡沫轴。

**【交叉】** 马克操专栏 cv8118914：非防伤必须项（见 `01`）。

### 4.2 跑后拉伸【UP 口播】BV1o7411F77p（约 2338 字）

**【UP 口播要点】**

1. 拉伸好不好、不拉有无坏处——**科学无定论**；本片只分享个人习惯（源自 GARMIN 训练营视频 + 其他跑者经验），**九个动作**顺序固定。  
2. 动作（各侧约 **15–30″**）：小腿（单腿+双腿 bonus）→ 大腿前侧 → 髂胫束/外侧 → 大腿后侧勾脚尖 → 臀+后侧（前置脚，手位可偏臀/ITB）→ 内收（侧伸）→ 坐姿脚掌相对内收 → 仰卧抱膝压臀 → **髂腰肌**（后膝可触地、躯干正直上伸）。  
3. **时机：** Easy/recovery 后可直接拉；**workout / long / 比赛后**先冷身、补水与蛋白能量，再轻拉，或当晚 recovery jog 后再拉——避免肌肉过紧时硬拉二次伤害。

### 4.3 拉伸与伤病【UP 口播】BV18 中的立场

拉伸对**部分**伤（口播举例足底、跟腱等）预防或有帮助；对某些**骨伤、肌肉伤**可能只有副作用——**不可一概而论**；本人习惯跑后 5–10′。

### 4.4 力量与柔韧性【云健身】BV1NC411t7NF（约 2426 字）

**【云健身要点】** 「不拉伸会变死肌肉」非全错：力量训可提高 **MTU（肌–腱复合体）刚性** → 柔韧表现下降；肌腱/韧带/筋膜随机械负荷肥大变硬（例 12 周肌腱肥大+硬度↑）。对策：力量同时安排拉伸（**勿放在力量训之前**——细节见其系列前作）；或尽量全幅度动作（离心段近似拉伸，但下肢许多动作幅度再大也难等效）。较高 MTU 刚性也有益：力更快传到骨 → 等长/单纯向心早期功率。死肌肉本身非学术概念。

**【综合】** 山雨：拉伸非防伤万能、因伤种而异；云健身：力量↑刚性↑时拉伸是**柔韧管理**工具——两线不冲突。

## 5. 伤期应对与复训

### 5.1 【UP 口播】如何面对伤病 · BV18Q4y1i7pp（约 5197 字）

> 后半多为交叉训练实拍 + 英文歌，口播要点集中在片头方法论。

**【个人经历立场（非处方）】**

1. 正式马训以来除不可抗力停约 2 月外很少连续多日不跑；**不是不受伤**，但对多数跑步类伤持 ***run through*** 观：忍着，**降量或降强度 + 加强力量**过渡。  
2. 经历过 ITBS、跑步膝、胫骨区、跟腱、足底、腘绳、小腿等，口播称未停跑且未拖成长期妨碍。  
3. 归因要点：大跑量（例完整周期周量至约 **80 mile / 128 km**）；绝大部分慢跑，临近比赛才抬高强度；身体稍有反应就改计划（速度日→轻松跑），**不在乎一两个 workout**；体感**完全休息不如降强度**对恢复更有意义。  
4. 伤初每天试能否跑；先用其他有氧：游泳、水中慢跑/挪动、骑车、椭圆、楼梯机、跳绳等。ITBS：**上坡/跑步机开坡**常明显减痛。  
5. 饮食：依赖碳水；有意识加蛋白；不吃补剂，但质量跑/长距离后立刻补蛋白饮料+碳水。  
6. 归根：量或强度相对力量不足 → **坚持力量**（自称不爱练，仍自重 1–3×/周）；上坡间歇等可部分替代跑向力量。

**【鸡汤收尾口播】**「在等待的日子里，刻苦读书，谦卑做人，养得深根，日后才能枝叶茂盛。」

**【综合警示】** *run through* 是**高训练史者的个人策略叙事**，不适用于应力骨折、急性撕裂、不明剧痛、神经症状等；笔记立场：区分 DOMS / 「越跑越坏」——后者减量并就医评估。

### 5.2 停训能力变化 · 交叉【UP 口播】BV1384（有氧线已整理）

伤病视角摘要：代谢数日即偏碳水；血容量约 1 周后明显；mito 量约 1–2 周起明显；力量 1–2 周可 5–10%↓（多神经）。策略：**保强度减量**；能慢跑则慢跑 + 可推强度的交叉；skip/跳绳等减力量流失；停 1–2 周有氧常需 **3–4 周**补回。详见 `02` §6。

### 5.3 冲击与交叉选择 · 交叉【UP 口播】BV12Vko

跑：近 LT 持续 + 离心冲击 → 恢复慢。车等：向心、负荷可波动 → 恢复快。伤期用非冲击有氧保心肺，与 BV18 交叉清单同向。

### 5.4 肌肉记忆与复训【云健身】BV146421c7Cc（约 3187 字）

**【云健身要点】**

| 问题 | 口播结论（量级供参考） |
|---|---|
| 力量掉速 | 停训后常有延迟；向心绝对力量可维约 **4 周**；离心与专项爆发掉更快 |
| 更长停训 | 约 **8–12 周**力量损失常仍限约 **7–12%**；很少掉到低于开训前（残余效应） |
| 肌量 | 例：14 天快肌 CSA ↓约 6.4%；慢肌不显著；7 月举重者纤维均萎缩可达约 30% 量级（个体差大） |
| 记忆效应 | 停训后再训，肌量/力量斜率可快于从未停训对照组，终点可接近；故疑似过度训练可大胆休息；例征兆多 → 至少休约 2 周；「练 6 月休 1 月」理论可但缺最佳比例研究 |
| 2X 纤维 | 停训后 2X 比例可回升甚至超训前——潜在好处，如何精确利用尚不清 |
| 机制推测 | 肥大时增加的**肌核**萎缩时不一定消失 → 复训重建更快 |
| 营养 | 复训快速增长期：**蛋白 +0.3–0.5 g/kg**、热量 **+300–500 kcal/d** 量级「宁多勿少」，感觉飞涨期过后可停 |

**【综合】** 力量记忆 ≠ 肌腱/骨应力已愈合；跑者复跑仍应按组织耐受渐进（对齐 Silbernagel RTS 思路），勿因「卧推还能推」就恢复冲击跑量。

## 6. 补剂 / 骨骼（【云健身】证据谨慎）

### 6.1 明胶水解物与氨基葡萄糖 · BV1B14y1L7Cc（约 1712 字）

**【云健身 · 转述《健身营养全书》】**

- 标记氨基酸进软骨**不能**证明明胶有特殊功效（吃鸡蛋也可能有氨基酸进软骨）。  
- 研究多、能说明有用的少；设计缺陷常见；老年关节炎样本**不可直接搬到年轻健身者**；厂家赞助「伪研究」需打折。  
- 结论倾向：关节损伤很大程度与**训练不当/体质**有关；明胶**证据不足，一般不非常推荐**；相对安全则可当「心情消费」。  
- 氨基葡萄糖：对运动人群有用性**基本不明确**；市售剂量常偏小；膝骨关节炎康复指南类表述口播概括为推荐强度「不明确」（不反对也不推荐）——鸡肋。  
- **尚无哪种补剂对健身人群有明确护关节作用** → 只能尽量安全合理训练。

### 6.2 酸碱、蛋白质与骨骼 · BV1kM4y1r7HB（约 5012 字）

**【云健身要点】**

1. 「酸性体质」长期存在多属伪科学；健康人有短暂 pH 波动，调节能力强。  
2. 运动（尤其无氧）局部乳酸等↑ → 酶受抑→力竭；组间休息呼吸等参与细胞外缓冲；β-丙氨酸→肌肽细胞内缓冲——耐力研究较多，力量者证据有限，训练本身可抬肌肽，个人不太建议力量者必补。  
3. 高蛋白「呈酸→脱钙伤骨」：学界**无明确负面结论**；研究互相矛盾，甚至有保护骨骼之说；风险叙事主要在**钙摄入过少**者。学者倾向：**蛋白不足比过多对骨危害更大**；保证钙够即可；高蛋白饮食往往也带钙。

**【综合】** 护关节补剂降级为可选；骨健康优先：**能量可用、钙、月经/内分泌、渐进冲击、肌力**——对齐 BV17 应力骨折段与 RED-S 交叉议题（框架已列，本线不展开诊疗）。

## 9. 可执行笔记要点（非医疗处方）

1. **第一杠杆：** 周负荷渐进；质量课密度可控；监控「越跑越痛 vs DOMS」。  
2. **第二杠杆：** 针对性力量——臀/髋外展、小腿–跟腱、大腿、核心、足内在；女生更留意髋力与骨健康。  
3. **跑姿：** 勿 overstride；不把商业改姿当防伤主菜；力量优先。  
4. **热身：** 先慢跑；质量课加 strides；动态操可选、服务「进区」。  
5. **拉伸：** 习惯可保留；高强度后勿立刻大力拉；按伤种决定是否强调（跟腱/足底 vs 某些骨/肌伤）。  
6. **伤期：** 能不掉有氧则交叉（车/游/椭圆/水跑/坡度减压）；能跑则常**保强度减量**——**前提是排除需停冲击的诊断**。  
7. **复训：** 力量有记忆可较快捡回；跑量/冲击另算；蛋白与热量短期可略增（云健身量级仅参考）。  
8. **补剂：** 不把氨糖/明胶当护身符；钙与能量可用优先于碱性焦虑。  
9. **就医红线：** 夜间骨痛、单腿蹦不可、肿胀锁定、神经症状、月经紊乱+骨应力疑——**停止自训实验，寻临床评估**。
