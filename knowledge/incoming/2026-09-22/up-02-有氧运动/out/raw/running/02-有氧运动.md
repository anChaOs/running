## 1. 主题定义与研究问题

**定义：** 耐力跑（及可迁移耐力）的有氧能力，是「能持续递送与利用氧气、并能在目标强度下维持代谢稳态」的综合能力。它不是单一 VO₂max 数字，而是多系统木桶：中枢泵血、血液/微循环运输、肌细胞氧利用、乳酸周转、脂肪氧化等共同决定。

**与框架文档的接口：** 表现 ≈ VO₂max × 可持续分数（LT/临界相关）× 经济性（Joyner & Coyle, 2008）。本笔记主攻前两块 + 底物选择；经济性/力量另见跑步理论与伤病笔记。

## 2. 有氧能力「木桶」五维详解

> 五维结构来自**【第三方】**二十二点消失的梨对山雨相关视频的整理（cv16277428），**非山雨专栏原文**。山雨 BV1pk4y167oM【视频原文】讲的是**间歇按生理学目的分类**，与五维「课型总排序」相关但**不是同一张表**——对照见 §3.3。

木桶隐喻：**最终耐力≈五维中最短板**；只练一块会在另一块见顶。

### 2.1 心脏氧气输出（Cardiac O₂ delivery / 中枢）

| 项 | 内容 |
|---|---|
| **机制（文献向）** | VO₂max 的中枢侧 ≈ 心输出量（Q）× 动静脉氧差的「输送端」；训练可增大每搏量、部分心室重塑，高强度更易推高接近 VO₂max 的心输出需求。 |
| **优先课型【第三方】** | Interval ＞ tempo ＞（不太快）long run ＞ easy/recovery。 |
| **【山雨口播·BV1pk】** | 心肺间歇：刺激越短越偏送氧、越长越偏用氧（不能太短心肺来不及、太长变肌肉耐力）；效果与待在 **≥90% VO₂max** 区时间成正比；实用 **3–5′** 组、累计 **15–30′**；或 30–60″ 短间歇（三十三十等）让心跳下不来。非短板可 **2–3 周一次**，做完常需 2–3 天恢复。 |
| **【云健身·急性 BV1L52】** | 单次有氧：Q 升至平台，最大可约静息 **4×**（例 5→20–22 L/min）；每搏靠舒张末期容积 + 儿茶酚胺增强收缩/排空（射血分数↑）。收缩压最大有氧可 **220–260**，舒张压多持平或略↓。 |
| **【云健身·VO₂max BV1Gjp】** | 几乎所有有效耐力训都能抬 VO₂max；中枢因素通常更关键；「低强度最抬 VO₂max」是误区；水平越高越依赖足够强度。VO₂max 平台后仍可借更高 %VO₂max 维持进步（见 §3.5）。 |
| **时间尺度【综合】** | 初训者数周可见 VO₂max↑；高训练者再抬更难，常需周期性 HIT。血容量相关变化可较快，结构适应更慢。 |
| **自测 / 代理指标** | 实验室 VO₂max / 分级测；场地：5k–3k 全力或已知 MAP 估测；同配速静息/运动心率趋势。**非金标准。** |

**【文献对照】** Joyner & Coyle (2008)；Seiler (2010) 约 80% 低强度 / 20% 含高强度。

### 2.2 氧气运输（O₂ transport：血红蛋白、毛细血管、肌红蛋白等）

| 项 | 内容 |
|---|---|
| **机制** | 通气→肺换气→心输出→血红蛋白→微循环→肌红蛋白缓冲。耐力训练经典外周适应含**毛细血管化**（Holloszy & Coyle, 1984）。山雨专栏转述 runnersconnect：**Capillary / myoglobin / Mitochondria**。 |
| **优先课型【第三方】** | （not fast）long run ＞ tempo ＞ interval ≈ medium-long easy ＞ recovery。 |
| **【山雨口播·停训】** | 停训先动血/血浆量；动脉血氧含量受影响「微小缓慢」；运输侧丢失主因每搏/心输出↓（BV1384y1a7rt）。 |
| **【云健身·通气 BV1Ne】** | 通气量=潮气量×频率；低–中强度先加深（潮气量），高强度再提频；加深通常比单纯提频更有效（解剖无效腔随深呼吸略增但仍净赚）。过度换气可致 CO₂ 过低→碱中毒症状。Hb 携带 O₂；贫血时运动表现受损 → 耐力补铁重要（接口补铁篇）。 |
| **【云健身·补铁 BV1aZ】** | 铁：Hb/肌红蛋白 + 电子传递链含血红素酶。不贫血也可缺铁（先耗**储存铁**/血清铁蛋白）。运动者需求↑、丢失↑、铁调素运动后 3–6 h↑抑制吸收。无贫血铁缺乏也可能损艰巨有氧与抵消训练适应。重度贫血就医；饮食干预见 §4.7。 |
| **时间尺度【第三方+综合】** | 慢变量：**数月–数年**（铁状态纠正亦常需数周–数月）。 |
| **自测 / 代理** | Hb / **铁蛋白**（注意急性期干扰）；同强度心率漂移；长距离可持续性；通气不适/赛前晕厥需排除过度换气等。 |

**【山雨专栏操作化】** 20′ 跑 5k 者为例：毛细血管约 **50–75% 5k pace**，肌红蛋白 **55–75%**，线粒体 **65–75%**；兼顾约 **65% 5k pace**。*try to gain the maximum benefit out of the least amount of stress*。

### 2.3 氧气利用（线粒体 / 肌纤维特异）

| 项 | 内容 |
|---|---|
| **机制【文献】** | 线粒体生物发生；AMPK、Ca²⁺、ROS → **PGC-1α** 等（Perry & Hawley, 2018；Holloszy & Coyle, 1984）。 |
| **优先课型【第三方】** | 「用什么增什么」：慢跑主增慢肌线粒体；高速可推慢肌+Ⅱa。 |
| **【山雨口播·BV1pk/停训】** | 乳酸重用依赖慢肌接快肌乳酸（shuttle）；停训主要掉线粒体**量**而非运转效率（澡盆水量 vs 保温能力比喻）；口播称训练强度偏影响「量」、训练量偏影响「效率」。 |
| **【云健身·BV1Cbra】** | Ⅰ型可有限肥大；2X→2A 更常见；大量Ⅱ→Ⅰ转化证据弱。 |
| **【云健身·BV1L52】** | 线粒体体积/数量↑ → 糖脂有氧氧化产能↑（长期适应逻辑入口）。 |
| **时间尺度** | 酶：数天–数周；含量/形态：数周–数月。 |
| **自测 / 代理** | 同配速 RPE↓、乳酸↓；Fatmax / RER↓。 |

### 2.4 乳酸利用（Lactate turnover / LT）

| 项 | 内容 |
|---|---|
| **机制【文献】** | Lactate 作燃料、糖异生前体与信号（Brooks, 2018）。 |
| **优先课型【第三方】** | interval ＞ tempo ＞ long run ＞ easy。 |
| **【山雨口播·BV1pk】** | **Reuse**：快跑约 LT **101–103%**，休息**必须 jog**；LT 穷人估≈可维 **50–60′** 最快配速。**Clearance**：近 LT 刺激 + 约 **85% LT** 主动恢复；初学者常 10k 配速。 |
| **时间尺度** | 数周质量课周期内可改善。 |
| **自测 / 代理** | 约 **1 h** 最高可持续配速【第三方+山雨口播同向】；实验室乳酸/通气阈。 |

### 2.5 脂肪利用（Fat oxidation）

| 项 | 内容 |
|---|---|
| **机制【文献】** | Romijn et al. (1993)：强度↑则碳水占比↑；高强度抑脂氧化。 |
| **优先课型【第三方】** | LSD >>>> easy ＞ tempo ＞ interval。 |
| **【山雨口播·停训】** | 停训**几天**即可提高碳水依赖、减少脂肪利用（BV1384y1a7rt）。 |
| **【云健身·BV1H84】** | 脂肪供能相对最慢；强度↑糖占比↑、时间↑脂肪占比↑；「30 分钟才开始耗脂」是错的；减脂≠只能低强度。 |
| **时间尺度** | 数周可见；与饮食/糖原强交互。 |
| **自测 / 代理** | Fatmax；长距离后期撞墙推迟；同强度 RER。 |

### 2.6 五维一览（速查）

| 维度 | 更吃的刺激（第三方排序） | 山雨/云健身口播补强 | 慢/快变量 |
|---|---|---|---|
| 心脏输出 | HIT / 间歇 | 3–5′ 或短间歇贴 VO₂max 区；2–3 周一次即可；云健身：中枢更关键、高水平吃强度 | 中–快（初训） |
| 氧运输 | 量×适度强度；long easy | 停训血容量先掉；通气加深优先；**铁/铁蛋白** | **慢** |
| 氧利用 | 纤维特异；质量+量 | 线粒体量易掉、效率相对保留；2X→2A | 中 |
| 乳酸利用 | 阈值～间歇 | reuse / clearance 两类间歇设计 | 中 |
| 脂肪利用 | 慢长 / 低强度 | 停训几天就偏碳水；破 30′ 燃脂神话 | 中–慢 |

**【综合判断】** mix + phase（梨文）∩ 大量 LIT + 少量 HIT（Seiler）∩ 最小 stress 最大收益（山雨专栏）∩ VO₂max 非唯一天花板（云健身）。

### 2.7 五维如何互相「拖后腿」（【综合】）

- **心脏强、运输弱：** 间歇「练得到」，长距离后半仍垮；或铁不足使运输木桶短板。  
- **运输强、乳酸弱：** 轻松能很久，一上节奏就垮——缺阈值区暴露。  
- **线粒体一般、脂肪弱：** 中等尚可，马后半「只有糖」。  
- **五项都不错、经济性差：** 见跑步理论·力量。  

**【与山雨专栏/口播接口】** 专栏把大众「慢」挂在 cap./myoglobin/mito 与 MAF/%5k；五维是第三方修辞；间歇原理视频提供**质量课怎么对准短板**的操作语言。

### 2.8 急性 vs 长期适应 + 通气一页（【云健身】）

| 层 | 来源 | 要点 |
|---|---|---|
| 急性 | BV1L52 | 单次：Q、每搏、血压、血流再分配、GI 风险；结束多回落 |
| 长期 | BV1Cbra + BV1L52 定义段 | 数月级稳定变化（VO₂max、线粒体、纤维型倾向等）；停数天不立刻消退 |
| 通气急性 | BV1Ne | 潮气量优先 → 高强度加频率；通气当量高强度可 >30；防过度换气 |
| 铁 | BV1aZ | 运输+线粒体产能交叉；见 §4.7 |

### 5.3 夏训周（【UP 口播】BV1dg411Z7YT +【文献】）

**【两个准则层 · 口播可核（AI 未清晰报「准则一/二」编号；desc 称两准则三点）】**

1. **夏冬不必大拆 + 保量：** 业余马者夏天与冬天训练不应有太大区分；核心维持跑量刺激。热天同等 LSD 恢复更长 → 长距离可拆两段、凉时跑；**恢复可以空调**；恢复不过来则减量。  
2. **配速分层：** 轻松/LSD **可降速**；**质量跑（节奏/MP 等）该打的配速一定要达到**（race pace 神经控制）。

**【三点建议 · 口播编号明确】** Progression / uptempo；Broken MP tempo（3–4×4–5 km）；少结构化 *feel good → hammer*。

**【文献叠加】** 热习服约 1–2 周（Racinais）。

## 8. 可执行笔记要点

1. **每周木桶自检：** ≥1 次真 Z1 长或足够 easy？1 次写清目标区的质量课？避免天天灰色区？
